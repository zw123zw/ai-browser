## 1. 🚀 快速开始

📸 截图：[扩展安装与首次配置界面]

### 1.1 安装扩展

1. 下载最新 CRX 包
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 开启右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」按钮
5. 选择解压后的文件夹，确认加载

安装成功后，浏览器右上角工具栏会出现图标，页面右下角出现浮动按钮。

### 1.2 首次配置 AI 模型

1. 点击浮动按钮或按 `Ctrl+`` ` 打开侧边栏
2. 点击右上角 ⚙️ 齿轮图标进入设置
3. 在「AI」标签页，点击「新建模型」
4. 点击提供商预设按钮（如 DeepSeek），自动填充
5. 填写 API Key，点击「保存」

> **提示：** 提供 10 个一键预设：OpenAI、Anthropic、DeepSeek、MiMo、Qwen、Kimi、智谱、百度、MiniMax、硅基流动。

### 1.3 打开侧边栏

| 方式 | 操作 | 说明 |
|------|------|------|
| 工具栏图标 | 点击浏览器右上角图标 | 最常用 |
| 键盘快捷键 | `Ctrl+`` ` | 可自定义 |
| 浮动按钮 | 点击页面右下角浮动按钮 | 任何页面可用 |

> **注意：** 侧边栏状态在所有标签页间同步。

### 1.4 浮动按钮

- **点击** — 打开/关闭侧边栏
- **拖拽** — 拖到任意位置（移动超 3px 才算拖拽）
- **位置记忆** — 自动保存，刷新后仍在原位

### 1.5 调整侧边栏宽度

拖动侧边栏左边缘手柄（最小 60px，最大 95% 视口宽度），宽度自动同步所有标签页。

## 2. 💬 AI 对话

📸 截图：[AI 对话界面与消息交互]

### 2.1 支持的 AI 提供商（14 个）

| 提供商 | 代表模型 |
|--------|----------|
| OpenAI | GPT-4o、GPT-4、GPT-3.5 |
| Anthropic | Claude Sonnet 4、Claude 3.5 Sonnet |
| Google Gemini | Gemini 1.5 Pro、Gemini 2.0 |
| DeepSeek | DeepSeek-V3、DeepSeek-R1 |
| MiMo | MiMo-v2.5-pro |
| Qwen (通义千问) | Qwen-Max、Qwen-Plus |
| Kimi (Moonshot) | Moonshot-v1-128k |
| 智谱 (Zhipu/ChatGLM) | GLM-4 |
| 文心一言 (Wenxin) | ERNIE-4.0 |
| MiniMax | MiniMax-Text |
| 硅基流动 (SiliconFlow) | 多种模型 |
| 豆包 (Doubao) | Doubao-pro |
| Grok | Grok-2 |
| 自定义 | 任何 OpenAI 兼容的 API |

### 2.2 发送消息

在输入框输入文字，按 **Enter** 发送，**Shift+Enter** 换行。AI 实时流式输出回复，点击 ⏹ 可中断。

> **💡 试试这样说：**
>
> - "你好，介绍一下你自己"
> - "帮我写一封请假邮件"
> - "用 Python 写一个快速排序"
> - "解释一下什么是量子计算"

### 2.3 切换模型

点击输入框下方的**模型名称药丸** → 下拉列表选择 → 立即切换。每个对话独立使用不同模型。

### 2.4 深度思考模式

点击 💡 灯泡图标开启（仅支持 reasoning 的模型如 DeepSeek-R1、Claude 3.7+）。AI 会先展示可折叠的「💭 深度思考」区块。

> **💡 试试这样说：**
>
> - "分析一下 React 和 Vue 的优缺点，需要深度分析"
> - "帮我设计一个电商系统的架构，需要详细思考"

### 2.5 文件附件

| 方式 | 操作 |
|------|------|
| 点击上传 | 📎 回形针图标，支持多选 |
| 粘贴图片 | 直接粘贴截图 |
| 粘贴 URL | 自动抓取页面内容 |
| 粘贴本地路径 | 如 `C:\Users\...\file.txt` |

**支持格式：**

| 类型 | 格式 | 限制 | 处理 |
|------|------|------|------|
| 图片 | jpg, png, gif, webp, bmp, svg | 20 MB | 自动 OCR（带进度条） |
| 文本 | txt, log, csv, tsv 等 | 2 MB | 直接读取 |
| 代码 | js, ts, py 等 60+ 种 | 2 MB | 语言检测 |
| PDF | pdf | 10 MB | 逐页提取 |
| Word | doc, docx | 10 MB | 提取文本 |
| Excel | xls, xlsx, csv, tsv | 10 MB | 导出 CSV |

> **注意：** 扫描版 PDF（纯图片）会提示无法提取文本。Excel 多工作表会分别标注。图片附件会显示 OCR 进度条。

> **💡 试试这样说：**
>
> - （上传截图后）"提取图片中的文字并翻译成英文"
> - （上传 PDF 后）"总结这篇文档的要点"
> - （上传代码后）"检查这段代码的问题并给出改进建议"

### 2.6 选中文字自动发送

| 模式 | 行为 |
|------|------|
| **自动发送**（默认） | 直接发送给 AI |
| **手动发送** | 填入输入框，手动确认 |
| **关闭** | 不处理 |

### 2.7 消息管理

| 操作 | 方式 |
|------|------|
| 清空对话 | 头部 🗑️ 图标 |
| 删除单条 | 右键消息 → 删除 |
| 复制内容 | 右键消息 → 复制内容 |
| 收藏为笔记 | 右键消息 → 收藏（可选择标题归档） |
| 中断回复 | ⏹ 停止按钮 |
| 滚动到底 | ⬇ 浮动按钮 |

### 2.8 消息内容交互

- **代码块** — 右上角复制按钮（1.5s 确认反馈），带语言标签
- **表格** — 右上角下载按钮（导出 Excel）
- **深度思考** — 可折叠区块
- **错误** — 红色横幅；停止 — 黄色横幅
- **数学公式** — 支持 LaTeX 渲染

### 2.9 输入历史

在空输入框按 **↑** 浏览历史（最多 100 条），**↓** 前进。

### 2.10 上下文管理

默认携带最近 100 条消息，可在设置中调整（100-500）。

### 2.11 交互式 AI 输入

AI 在执行任务过程中可暂停并请求用户输入（如验证码、密码等私密信息），用户提供信息后继续执行。无需重新描述任务。输入栏会显示 AI 的提示文字。

> **💡 试试这样说：**
>
> - "帮我登录，用户名是 admin，密码是 123456"
> - AI 执行过程中会自动询问缺失信息

### 2.12 语音模式切换

点击输入框左侧 🎙️ 图标切换到语音模式，语音面板会替代聊天面板。点击返回箭头回到文字模式。语音模式状态跨页面保持。

### 2.13 AI 操作反馈

AI 执行网页操作时，对话中会显示实时反馈：

- `🔧 正在执行指令 N：操作描述` — 开始执行
- `✅ 操作成功 — 详细信息` — 执行成功
- `❌ 操作失败 — 错误原因` — 执行失败
- `🔄 重试指令 N（5/50）` — 失败重试中
- `⏹ 已停止` — 用户中断

AI 分析页面结构 → 生成操作命令 → 逐步执行 → 遇错自动重试（最多 50 步）→ 批量命令最多 20 条。

### 3.2 自然语言操作

> **💡 试试这样说：**
>
> - "滚动到页面底部"
> - "点击搜索按钮"
> - "在搜索框中输入 Vue3 教程"
> - "帮我打开百度搜索 AI 新闻"

> - "打开新标签页"

> - "切换到 B 站"
> - "帮我切换到 GitHub 标签页"

支持中文别名：B站→bilibili.com、淘宝→taobao.com、京东→jd.com、百度→baidu.com、知乎→zhihu.com 等。

### 3.9 数据提取与页面总结

页面总结采用三层递进分析框架，输出结构化 Markdown，可直接收藏为笔记：

- **第一层 · 提取** — 快速识别页面主题、内容类型、目标读者
- **第二层 · 分析** — 深入拆解关键论点、数据证据、逻辑脉络
- **第三层 · 洞察** — 超越内容的深层见解、盲区、行动建议

输出包含：核心摘要、深度分析（关键要点 + 数据与证据 + 逻辑脉络）、洞察与启发、行动建议、关键词标签。自动适配不同内容类型（文章、产品页、数据表格、文档、讨论帖）。

> **💡 试试这样说：**
>
> - "把这个页面的内容总结一下"
> - "分析一下这篇技术文章的核心观点"
> - "提取页面上的所有链接"
> - "把页面上的商品信息整理成表格"
> - "下载这个页面的数据为 Excel"

### 3.10 富文本编辑器支持

AI 可以自动识别并输入以下富文本编辑器：CodeMirror 5/6、Monaco Editor、Ace Editor、Quill、TinyMCE、CKEditor、ProseMirror/TipTap、Draft.js、WangEditor，以及通用 contenteditable 元素。

### 3.11 跨标签页任务恢复

页面跳转时进度自动保存，新页面自动恢复执行（30 秒过期保护）。点击链接打开新标签页时，任务也会自动传递。

### 3.12 批量命令

AI 可一次返回多个命令（最多 20 条）按序执行，单个失败不阻塞后续。

### 3.13 iframe 与 Shadow DOM 内元素操作

AI 可以操作 iframe 和 Shadow DOM 内部的元素（如嵌入的编辑器、表单等），支持同源 iframe（最深 5 层）、跨域 iframe 和 Shadow DOM（最深 10 层）。

### 3.14 弹窗自动关闭

AI 可自动关闭页面弹窗，支持原生对话框、ARIA 弹窗，以及 Bootstrap、Element UI、Ant Design、Material UI、Vuetify 等框架的弹窗组件。

### 3.15 文件上传操作

AI 可以自动将文件上传到页面的文件输入框，智能检测隐藏的上传组件（如 Element UI、Ant Design 的上传控件）。

## 4. 🎤 语音控制

默认唤醒词为「你好，小灵」，可在设置中自定义。支持一句话同时包含唤醒词和指令：

### 4.5 语音消息类型

- 🗣️ 你 — 右对齐，主题色背景

### 4.6 语音播报（TTS）

开启后 AI 回复会自动朗读。可调节语速（0.5x-2.0x）和音量（0%-100%）。播报过程中说话会自动打断播报并进入指令模式。

### 4.7 常驻语音模式

开启「常驻语音」后，语音引擎持续运行，无需手动开启麦克风。关闭侧边栏后仍可通过唤醒词唤醒。

### 4.8 语音设置引导

点击语音面板中的 📖 引导按钮，打开 5 页引导文档：快速开始、引擎配置、权限说明、注意事项、常见问题。

> **注意：** 关闭自动化后变为纯聊天模式。支持单次语音输入多条命令。同一时间只有一个标签页可以使用麦克风。

## 5. 🌍 智能翻译

📸 截图：[翻译模式与划词翻译效果]

### 5.1 翻译模式

| 模式 | 适合场景 |
|------|----------|
| 划词翻译 | 偶尔查词 |
| 自动翻译 | 整页阅读 |
| 点击翻译 | 按需翻译段落 |
| 关闭 | 不需要翻译 |

在设置 → 通用配置 → 翻译模式中选择。

### 5.2 划词翻译

选中文字 → 自动弹出浮窗 → 显示译文 → 复制按钮 → 点击外部关闭。浮窗支持拖拽移动和四边调整大小。

### 5.3 自动翻译

所有可见文本自动翻译，相同文本只翻译一次，`<code>` 元素保留不翻译，动态加载内容也自动翻译。翻译过程中显示加载动画，关闭自动翻译后所有译文自动恢复原文。

### 5.4 点击翻译

点击段落翻译，再次点击隐藏，第三次显示缓存结果。支持段落、列表、表格、标题等。点击表格行翻译整个表格。

### 5.5 目标语言（8 种）

中文、English、日本語、한국어、Français、Deutsch、Español、Русский

### 5.6 代码保护

三层保护机制确保代码不被误翻译：

- **标签黑名单** — `<pre>`/`<code>`/`<samp>` 整体跳过
- **类名黑名单** — 含 `hljs`、`language-`、`prism`、`shiki` 等类名的元素跳过
- **正则替换** — 行内代码、URL、函数调用、JSON 片段等替换为占位符后恢复

### 8.1 什么是笔记系统

笔记系统可以将 AI 生成的内容、网页摘要、翻译结果等保存为结构化 Markdown 笔记，按标题分组管理，支持导出和导入。

### 8.2 收藏笔记

有多种方式触发收藏：

| 方式 | 操作 |
|------|------|
| 右键消息 | 右键任意 AI 回复 → 收藏 |

| 点击翻译卡片 | 翻译结果中点击 ⭐ 收藏按钮 |
| 自动笔记 | 页面加载时自动生成笔记（设置中开启） |

收藏时弹出对话框，输入或选择已有标题即可归档。支持标题自动补全。

> **💡 试试这样说：**
>
> - "总结这个页面的内容"（生成后可收藏为笔记）
> - "帮我翻译这段话"（翻译后可收藏）

- **右侧栏** — 时间线，显示每条笔记的来源链接和时间

### 8.4 编辑笔记

### 8.7 删除笔记

鼠标悬停标题显示删除按钮，或在笔记卡片底部点击删除。删除前有确认对话框。

## 12. 💡 使用技巧

📸 截图：[使用技巧与最佳实践]

### 对话效率

- **指令越明确越好** — "点击登录按钮" 比 "帮我操作" 效果好
- **复杂任务拆分多步** — 分步执行更可靠
- **利用上下文** — "接着刚才的继续"
- **中断重来** — 点停止按钮，重新描述

### 文件处理

- **OCR + 翻译** — 上传截图要求"提取文字并翻译成英文"
- **PDF 分析** — 上传 PDF 要求"总结要点"
- **代码审查** — 上传代码要求"检查问题并给出改进建议"

### 翻译与笔记

- **划词翻译**适合偶尔查词，**自动翻译**适合整页阅读
- **点击翻译**最轻量，按需翻译不干扰阅读
- **笔记模式**可自动生成页面笔记，收藏后可随时查看
- 翻译和笔记结果都可以一键收藏为笔记

### 语音控制

- 唤醒词 + 指令可以说一句话："你好小灵，打开百度"
- 播报中说话会自动打断并进入指令模式
- 常驻语音模式下无需手动开启麦克风
- 安静环境、清晰发音可提高识别准确率

### 笔记管理

- 按主题给笔记命名，方便归档查找
- 利用标题自动补全快速归档到已有分类
- 导出为 `.zip` 可备份所有笔记
- 点击时间线链接可跳转回原始页面

### 设置

- **模型导入导出** — 团队共享配置
- **上下文 100-200** — 日常对话足够
- **缓存管理** — 定期清理保持流畅（上限 30MB）
- **语音引擎切换** — 国内推荐讯飞/百度/腾讯，海外用 Web Speech

## 13. ❓ 常见问题

📸 截图：[常见问题解答]

**Q: 打开侧边栏没反应？** 检查是否配置了模型、API Key 是否正确、网络是否正常。

**Q: AI 回复很慢？** 减少上下文消息数、切换更快模型、检查网络。

**Q: 自动化无法点击？** 元素可能在 iframe 中或被遮挡，用更精确的描述重试。AI 会自动尝试在 iframe 和 Shadow DOM 中查找元素。

**Q: 语音识别不准？** 确保麦克风权限、安静环境、说话清晰。可尝试切换引擎（讯飞/百度/腾讯各有优势）。

**Q: 唤醒词不响应？** 检查麦克风权限，确认唤醒词设置正确，尝试说话清晰一些。唤醒词支持模糊匹配，允许少量口误。

**Q: 切换语音引擎需要重新配置吗？** 不需要，每个引擎的凭证独立保存，切换后之前的配置会保留。

**Q: 文件上传失败？** 检查大小限制：图片 20MB、文本 2MB、PDF/Office 10MB。

**Q: 怎么切换模型？** 点击输入框下方的模型名称药丸。

**Q: 怎么调侧边栏宽度？** 拖动左边缘手柄。

**Q: 怎么备份配置？** 设置 → 模型配置 → 导出。

**Q: 怎么备份笔记？** 笔记查看器 → 全部导出 → 下载 `.zip` 文件。

**Q: 清除缓存丢失什么？** 清除会话/日志/历史，保留个性化配置和笔记。

**Q: 浮动按钮挡内容？** 拖到其他位置，自动保存。

**Q: 命令选择器不弹出？** 确保自动化开关已开启，输入以 `/` 开头。

**Q: 翻译把代码也翻译了？** 代码已自动保护，`<code>`/`<pre>` 元素不会被翻译。如遇异常请反馈。

**Q: 笔记来源链接打不开？** 原始页面可能已删除或移动，链接会尝试打开并定位到保存时的滚动位置。

**Q: 同时开多个标签页语音会冲突？** 同一时间只有一个标签页可以使用麦克风，其他标签页会自动释放。
