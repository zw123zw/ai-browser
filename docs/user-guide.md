## 1. 🚀 快速开始

### 1.1 安装扩展

1. 下载扩展包并解压到本地文件夹
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 开启右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」按钮
5. 选择解压后的文件夹，确认加载

📸 截图：chrome://extensions/ 页面，开发者模式开关和加载按钮

安装成功后，浏览器右上角工具栏会出现 AI Browser 图标。

📸 截图：工具栏中的扩展图标

### 1.2 首次配置 AI 模型

安装后需要至少配置一个 AI 模型才能使用：

1. 点击工具栏中的 AI Browser 图标，打开侧边栏
2. 点击侧边栏右上角的 ⚙️ 齿轮图标进入设置
3. 在「模型配置」标签页中，点击「+ 新建」按钮
4. 点击提供商预设按钮（如 DeepSeek、OpenAI 等），自动填充大部分字段
5. 填写你的 API Key
6. 点击「保存」按钮

📸 截图：设置 → 模型配置，点击预设按钮 → 填写 API Key → 保存

> **提示：** 设置页提供 10 个一键预设：OpenAI、Anthropic、DeepSeek、MiMo、Qwen、Kimi、智谱、百度、MiniMax、硅基流动。点击即可自动填充 API 地址等字段，只需填写 API Key 即可。

### 1.3 打开侧边栏

三种方式打开：

| 方式 | 操作 | 说明 |
|------|------|------|
| 工具栏图标 | 点击浏览器右上角的 AI Browser 图标 | 最常用 |
| 键盘快捷键 | 按 `Ctrl+`` ` | 默认快捷键，可在设置中自定义 |
| 浮动按钮 | 点击页面右下角的浮动按钮 | 任何页面都可用 |

📸 截图：三种打开方式的标注图

> **注意：** 侧边栏的状态会在所有标签页间同步。在一个标签页打开侧边栏，其他标签页也会自动打开。

### 1.4 浮动按钮

页面右下角有一个 48×48 像素的浮动按钮，可以：

- **点击** — 打开/关闭侧边栏
- **拖拽** — 按住拖动到页面任意位置（移动超过 3px 才算拖拽，否则视为点击）
- **位置记忆** — 拖拽后的新位置会自动保存，刷新页面后仍在原位

📸 截图：浮动按钮位置和拖拽示意

> **提示：** 浮动按钮悬停时会显示工具提示，提示当前设置的快捷键。

## 2. 💬 AI 对话

### 2.1 支持的 AI 提供商

AI Browser 支持 11 个 AI 提供商，覆盖国内外主流大模型：

| 提供商 | 代表模型 |
|--------|----------|
| OpenAI | GPT-4o、GPT-4、GPT-3.5 |
| Anthropic | Claude 3.5 Sonnet、Claude 4 |
| Google Gemini | Gemini 1.5 Pro、Gemini 2.0 |
| DeepSeek | DeepSeek-V3、DeepSeek-R1 |
| Qwen (通义千问) | Qwen-Max、Qwen-Plus |
| Kimi (Moonshot) | Moonshot-v1-128k |
| 智谱 (ChatGLM) | GLM-4 |
| 文心一言 | ERNIE-4.0 |
| 豆包 | Doubao-pro |
| Grok | Grok-2 |
| 自定义 | 任何 OpenAI 兼容的 API |

### 2.2 发送消息

1. 在侧边栏底部的输入框中输入文字
2. 按 **Enter** 发送消息
3. AI 会实时流式输出回复（逐字显示）

**输入框操作：**

| 按键 | 效果 |
|------|------|
| **Enter** | 发送消息 |
| **Shift+Enter** | 换行（不发送） |

发送后输入框旁的按钮会变成 ⏹ 停止按钮，点击可中断 AI 回复。

📸 截图：输入框、发送按钮、流式输出过程

### 2.3 切换模型

每个对话可以独立使用不同的模型：

1. 点击输入框下方工具栏中的**模型名称药丸**（显示当前模型名称）
2. 在弹出的下拉列表中选择其他模型
3. 点击后立即切换，后续消息使用新模型

📸 截图：模型选择下拉列表

> **提示：** 下拉列表中会显示所有已配置的模型。如果列表为空，需要先在设置中添加模型。

### 2.4 深度思考模式

部分模型支持深度思考（如 DeepSeek-R1、Claude 3.7+）：

1. 点击输入框下方的 💡 灯泡图标
2. 图标高亮表示已开启
3. 发送消息后，AI 会先展示思考过程（显示为可折叠的「💭 深度思考」区块）
4. 思考完成后输出正式回答

📸 截图：深度思考开关、思考过程展示

> **注意：** 深度思考模式仅对支持 reasoning 的模型生效。如果当前模型不支持，切换不会有任何效果。

### 2.5 文件附件

发送消息时可以附带文件，AI 会读取文件内容进行分析。

**上传方式：**

| 方式 | 操作 |
|------|------|
| 点击上传 | 点击输入框左侧的 📎 回形针图标，在文件选择器中选择文件（支持多选） |
| 粘贴图片 | 将截图或复制的图片粘贴到输入框 |
| 粘贴 URL | 粘贴网页链接，自动抓取页面内容 |
| 粘贴本地路径 | 粘贴如 `C:\Users\...\file.txt` 的本地路径，自动读取文件 |

**上传后的显示：**

- 图片 → 显示缩略图预览，自动触发 OCR 文字识别（显示蓝色进度条）
- 其他文件 → 显示文件图标、文件名、文件大小的芯片卡片

📸 截图：图片缩略图带 OCR 进度条、非图片文件芯片

**支持的文件格式和大小限制：**

| 类型 | 格式 | 大小限制 | 处理方式 |
|------|------|----------|----------|
| 图片 | jpg, png, gif, webp, bmp, svg | 20 MB | 自动 OCR 识别中英文文字 |
| 文本 | txt, log, csv, tsv, readme 等 | 2 MB | 直接读取文本内容 |
| 代码 | js, ts, py, java, go, html, css, vue 等 60+ 种 | 2 MB | 读取内容 + 自动检测编程语言 |
| PDF | pdf | 10 MB | 逐页提取文字（扫描件无文字） |
| Word | doc, docx | 10 MB | 提取纯文本 |
| Excel | xls, xlsx, csv, tsv | 10 MB | 导出为 CSV 格式 |

**管理附件：**
- 点击图片缩略图 → 打开文件预览
- 点击文件芯片 → 打开文件预览
- 点击缩略图/芯片上的 ✕ → 删除附件

📸 截图：多种文件类型上传后的显示效果

> **注意：** 超过大小限制的文件会显示错误提示。粘贴的文本超过 500KB 会被截断，并在卡片上显示截断警告。

### 2.6 选中文字自动发送

在网页上选中一段文字后，可以根据设置自动发送给 AI：

| 模式 | 行为 |
|------|------|
| **自动发送**（默认） | 选中文字自动填入输入框并直接发送给 AI |
| **手动发送** | 选中文字填入输入框，需要手动按 Enter 发送 |
| **关闭** | 选中文字不做任何操作 |

在设置 → 通用配置 →「选中文字操作」中切换。

📸 截图：选中文字后自动发送的效果

### 2.7 消息管理

| 操作 | 方式 | 说明 |
|------|------|------|
| 清空对话 | 点击侧边栏头部的 🗑️ 图标 | 弹出确认对话框，确认后清空所有消息 |
| 删除单条消息 | 右键点击消息 → 选择「删除」 | 只删除这一条消息 |
| 复制消息内容 | 右键点击消息 → 选择「复制内容」 | 复制到剪贴板 |
| 中断 AI 回复 | 点击输入框旁的 ⏹ 停止按钮 | 停止当前流式输出 |
| 滚动到底部 | 向上滚动后，点击右下角 ⬇ 按钮 | 快速回到最新消息 |

📸 截图：右键消息弹出的上下文菜单

> **注意：** 清空对话后，下次发送消息时不会携带任何历史上下文，相当于开始一个全新的对话。

### 2.8 消息内容交互

AI 回复的消息中包含丰富的可交互内容：

**代码块：**
- 每个代码块右上角有 📋 复制按钮
- 点击后代码复制到剪贴板，按钮变为 ✅ 确认标记（1.5 秒后恢复）

**表格：**
- AI 回复中的表格右上角有 📥 下载按钮
- 点击可将表格导出为 Excel 文件（`table.xlsx`）

**深度思考区块：**
- 显示为可折叠的「💭 深度思考」区块
- 点击标题可展开/折叠思考过程

**错误状态：**
- 请求失败 → 红色错误横幅，显示错误信息
- 手动停止 → 黄色横幅，显示「已停止生成」

📸 截图：代码块复制按钮、表格下载按钮、深度思考区块、错误横幅

### 2.9 输入历史

每次发送的非空文本会自动记录：

1. 在**空输入框**中按 **↑** 键 → 浏览历史输入（从新到旧）
2. 按 **↓** 键 → 前进到更新的历史
3. 到达最新条目时恢复之前的草稿
4. 最多保存 100 条历史记录

📸 截图：按 ↑ 键浏览历史输入

### 2.10 上下文管理

- AI 每次请求会携带最近 N 条消息作为上下文
- 默认 50 条，可在设置 → 用户配置中调整（范围 5-200）
- 超过限制时，最早的消息会被自动裁剪
- 裁剪不影响对话记录，只是不发送给 AI

> **提示：** 上下文越多，AI 回答越有连贯性，但消耗的 token 也越多。建议根据使用场景调整。

## 3. 🌐 网页自动化

### 3.1 工作原理

AI Browser 会自动分析当前页面的结构（按钮、链接、输入框等），将信息发送给 AI，AI 根据你的指令生成操作命令并逐步执行。

> **注意：** 网页自动化需要在设置中开启「网页自动化」开关（默认开启）。关闭后 AI 仅作为聊天助手，不会执行任何页面操作。

### 3.2 自然语言操作

不需要记忆命令，直接用自然语言描述你想做的事：

> **示例：**
>
> - "滚动到页面底部"
> - "点击搜索按钮"
> - "在搜索框中输入 Vue3 教程"
> - "帮我打开百度搜索 AI 新闻"
> - "总结一下这个页面的内容"
> - "把页面上的表格下载为 Excel"
> - "帮我登录，用户名是 admin，密码是 123456"

📸 截图：输入自然语言指令后的执行过程

AI 会自动：
1. 分析页面结构
2. 确定需要执行的操作
3. 逐步执行（每步执行后重新分析页面状态）
4. 遇到错误自动重试（最多 5 次）
5. 最多执行 20 步

### 3.3 快速命令（即时执行）

这些命令不需要分析页面结构，可以立即执行：

| 命令 | 说明 | 示例 |
|------|------|------|
| `/navigate` | 打开指定 URL | `/navigate https://github.com` |
| `/scroll` | 滚动页面 | `/scroll down`、`/scroll top`、`/scroll auto` |
| `/newTab` | 新建标签页 | `/newTab` |
| `/closeTab` | 关闭当前标签页 | `/closeTab` |
| `/nextTab` | 切换到下一个标签页 | `/nextTab` |
| `/prevTab` | 切换到上一个标签页 | `/prevTab` |
| `/switchTab` | 按关键词切换标签页 | `/switchTab github` |
| `/keyboard` | 模拟按键 | `/keyboard Enter`、`/keyboard Escape` |
| `/wait` | 等待指定毫秒 | `/wait 2000` |

### 3.4 页面操作命令

这些命令需要分析页面结构后执行：

| 命令 | 说明 | 示例 |
|------|------|------|
| `/search` | 网页搜索 | `/search AI 新闻` |
| `/click` | 点击页面元素 | `/click 登录按钮` |
| `/type` | 在输入框中输入文字 | `/type 搜索框 hello world` |
| `/clear` | 清空输入框 | `/clear 搜索框` |
| `/select` | 选择下拉菜单选项 | `/select 国家下拉框 中国` |
| `/focus` | 聚焦到元素 | `/focus 邮箱输入框` |
| `/hover` | 鼠标悬停在元素上 | `/hover 菜单项` |
| `/download` | 提取页面数据并导出文件 | `/download` |
| `/summarize` | 分析总结页面内容 | `/summarize` |

### 3.5 控制命令

| 命令 | 说明 |
|------|------|
| `/stop` | 停止当前操作 |
| `/pause` | 暂停当前操作 |
| `/resume` | 恢复暂停的操作 |

### 3.6 滚动控制

滚动命令支持多种模式：

| 方向 | 说明 | 示例 |
|------|------|------|
| `up` | 向上滚动（默认滚动 80% 视口高度） | `/scroll up` |
| `down` | 向下滚动 | `/scroll down` |
| `top` | 滚动到页面/容器顶部 | `/scroll top` |
| `bottom` | 滚动到页面/容器底部 | `/scroll bottom` |
| `auto` | 开始自动滚动（持续向下） | `/scroll auto` |
| `stop` | 停止自动滚动 | `/scroll stop` |
| `pause` | 暂停自动滚动 | `/scroll pause` |
| `resume` | 恢复自动滚动 | `/scroll resume` |

**自动滚动特性：**
- 刷新页面或切换标签页后仍保持滚动状态
- 鼠标滚轮向上滚动 → 自动暂停
- 鼠标滚轮向下滚动 → 自动恢复
- 适合长时间阅读长文章或自动浏览信息流

📸 截图：自动滚动状态指示

### 3.7 视频控制

页面上有视频时，可以通过自然语言控制：

> **示例：**
>
> - "播放视频" / "暂停视频"
> - "把音量调到 50%"
> - "静音" / "取消静音"
> - "快进 30 秒" / "后退 10 秒"
> - "跳到 2 分钟的位置"
> - "2 倍速播放"

> **注意：** 全屏操作需要用户手势，AI 无法直接触发。可以改为"点击视频的全屏按钮"。

### 3.8 标签页管理

通过自然语言或命令管理浏览器标签页：

> **示例：**
>
> - "打开新标签页"
> - "关闭当前标签页"
> - "切换到下一个标签页"
> - "帮我切换到 GitHub 标签页"
> - "切换到 B 站"

**标签页切换支持中英文别名匹配：**

| 关键词 | 匹配网站 |
|--------|----------|
| bilibili / B站 | bilibili.com |
| taobao / 淘宝 | taobao.com |
| jd / 京东 | jd.com |
| baidu / 百度 | baidu.com |
| google | google.com |
| github | github.com |
| zhihu / 知乎 | zhihu.com |
| weibo / 微博 | weibo.com |
| douyin / 抖音 | douyin.com |
| youtube | youtube.com |
| twitter / X | twitter.com |

### 3.9 数据提取

**`/download` — 提取页面数据**

提取页面上的文本数据（表格、列表、段落等），AI 自动格式化后生成可下载的文件。

**`/summarize` — 总结页面**

提取页面全文内容，由 AI 进行分析总结，输出结构化的摘要。

> **示例：**
>
> - "把这个页面的内容总结一下"
> - "提取页面上的所有链接"
> - "把页面上的商品信息整理成表格"

### 3.10 跨标签页任务恢复

当自动化操作涉及页面跳转（如点击链接打开新页面）时：
- 当前执行进度会自动保存
- 在新页面打开后，可以恢复之前的任务继续执行
- 已完成的步骤会被跳过，从断点处继续

## 4. 🎤 语音控制

### 4.1 开启语音模式

1. 点击输入框左侧的 🎤 麦克风图标
2. 侧边栏从聊天面板切换到语音面板
3. 点击中央的大麦克风按钮开始语音识别

📸 截图：语音面板界面

### 4.2 语音识别引擎

系统会自动选择最佳的识别引擎：

| 引擎 | 类型 | 特点 |
|------|------|------|
| **Sherpa-ONNX**（优先） | 本地离线 | 无需网络，完全在浏览器内运行，支持中英双语 |
| **Web Speech API**（备选） | 在线 | 浏览器原生 API，需要网络连接 |

系统会优先尝试加载本地引擎，如果失败则自动回退到在线引擎。

### 4.3 交互流程

```
空闲 → 点击麦克风 → 聆听中 → AI 处理中 → 语音播报 → 空闲
```

**状态指示器：**

| 状态 | 指示器颜色 | 状态文字 | 说明 |
|------|-----------|----------|------|
| 空闲 | 灰色圆点 | "点击麦克风开始" | 等待开始 |
| 聆听中 | 绿色脉冲圆点 | "正在聆听..." | 正在录音，实时显示识别中的文字 |
| 处理中 | 主题色脉冲圆点 | "处理中..." | AI 正在分析和生成回复 |
| 播报中 | 紫色脉冲圆点 | "播报中..." | 正在播放 AI 的语音回复 |

📸 截图：四种状态的指示器

**麦克风按钮：**
- 默认状态：白色背景，灰色边框
- 聆听中：主题色填充，外层有三层扩散的涟漪动画
- 悬停时：边框变主题色，按钮轻微放大

📸 截图：麦克风按钮的默认和聆听状态

### 4.4 语音消息类型

语音对话中会显示三种消息：

| 类型 | 对齐 | 样式 | 说明 |
|------|------|------|------|

## 5. 🌍 智能翻译

### 5.1 翻译模式

AI Browser 提供四种翻译模式：

| 模式 | 怎么用 | 适合场景 |
|------|--------|----------|
| **划词翻译** | 选中文字后自动弹出翻译浮窗 | 阅读时偶尔查词 |
| **自动翻译** | 自动翻译进入视口的所有文本 | 浏览外文网站 |
| **点击翻译** | 点击文本段落触发翻译 | 按需翻译特定段落 |
| **关闭** | 不启用翻译功能 | 不需要翻译 |

在设置 → 通用配置 →「翻译模式」中选择。

### 5.2 划词翻译

1. 在页面上选中一段文字
2. 自动弹出翻译浮窗，显示加载动画
3. 翻译完成后显示译文
4. 可点击「复制」按钮复制译文
5. 点击浮窗外部或滚动页面自动关闭

**浮窗特性：**
- 最大宽度 400px
- 距选区 8px 偏移
- 支持原文/译文对照
- 复制按钮一键复制

📸 截图：划词翻译浮窗

### 5.3 自动翻译

开启后，页面上所有可见文本会自动翻译为目标语言：
- 新进入视口的文本会自动触发翻译
- 相同的文本只翻译一次，结果应用到所有匹配位置
- 行内 `<code>` 元素会自动保留不翻译
- 新动态加载的内容也会自动翻译

> **提示：** 自动翻译适合整页阅读外文网站。如果页面元素过多，可能会影响性能。

### 5.4 点击翻译

1. 开启点击翻译模式
2. 点击页面上的文本段落
3. 该段落自动翻译并替换显示
4. 再次点击 → 恢复原文
5. 第三次点击 → 重新显示译文

**支持点击的元素：** 段落、列表项、表格单元格、标题（h1-h6）、引用块、代码块、文章区块等。

**特殊处理：**
- 点击表格行 → 翻译整个表格
- 点击列表项（多个时）→ 翻译整个列表
- 点击定义列表项 → 翻译整个定义列表

📸 截图：点击翻译前后的对比

### 5.5 翻译目标语言

支持 8 种目标语言：

| 语言 | 选项 |
|------|------|
| 中文 | 默认 |
| English | 英语 |
| 日本語 | 日语 |
| 한국어 | 韩语 |
| Français | 法语 |
| Deutsch | 德语 |
| Español | 西班牙语 |
| Русский | 俄语 |

### 5.6 代码保护

翻译时会自动识别并跳过代码内容：

- `<pre>`、`<code>`、`<samp>` 标签内的代码整体跳过
- 含 `hljs`、`language-`、`code-block` 等类名的元素跳过
- 行内代码（反引号、URL、函数调用、JSON、注释等）替换为占位符，翻译后恢复

> **提示：** 这意味着翻译技术文档时，代码部分不会被错误翻译。

## 11. 💡 使用技巧

### 对话效率

- **指令越明确越好** — "点击页面上的登录按钮" 比 "帮我操作一下" 效果好得多
- **复杂任务拆分多步** — 分步执行比一步到位更可靠
- **利用上下文** — AI 记得之前的对话，可以说"接着刚才的继续"
- **中断重来** — AI 执行方向不对？点停止按钮中断，重新描述需求

### 文件处理

- **OCR + 翻译** — 上传截图后要求"提取图片中的文字并翻译成英文"
- **PDF 分析** — 上传 PDF 后要求"总结这篇文档的要点"
- **代码审查** — 上传代码文件后要求"检查这段代码的问题并给出改进建议"
- **批量处理** — 支持同时上传多个文件

### 翻译

- **划词翻译**适合偶尔查词，**自动翻译**适合整页阅读
- **点击翻译**最轻量，按需翻译不干扰阅读
- 翻译会自动过滤代码块，技术文档翻译更准确

### 语音

- 语音命令尽量简洁："打开百度"、"搜索新闻"、"下一页"
- 复杂指令建议用文字输入
- 本地引擎首次加载可能需要几秒钟

### 设置

- **模型导入导出** — 团队共享模型配置的最便捷方式
- **上下文消息数** — 日常对话建议 20-50，长文档分析可调高
- **缓存管理** — 定期清理保持扩展流畅

### 跨标签页

- 标签页切换支持中文别名："淘宝" → taobao.com
- 所有标签页共享同一个对话和设置
- 自动化操作涉及页面跳转时，任务会自动保存到断点

## 12. ❓ 常见问题

**Q: 打开侧边栏后没有任何反应？**
检查以下几点：
1. 是否已在设置中配置了至少一个 AI 模型
2. API Key 是否正确
3. API 地址是否可访问
4. 检查网络连接

**Q: AI 回复很慢？**
- 减少「上下文消息数」设置
- 切换到更快的模型
- 检查网络延迟

**Q: 网页自动化无法点击某些元素？**
- 元素可能在 iframe 中（暂不支持跨 iframe 操作）
- 元素可能被其他元素遮挡
- 元素可能需要先手动触发才能出现
- 尝试用更精确的描述重试

**Q: 翻译不准确？**
- 检查翻译目标语言设置是否正确
- 自动翻译模式下，某些代码块可能未被过滤
- 可以切换到「点击翻译」模式按需翻译

**Q: 语音识别不准确？**
- 确保已授予麦克风权限
- 安静环境下效果更好
- 说话尽量清晰，避免过长句子
- 本地引擎对中文效果更好

**Q: 文件上传失败？**
检查文件大小限制：
- 图片：最大 20 MB
- 文本/代码：最大 2 MB
- PDF/Office：最大 10 MB

**Q: 怎么切换 AI 模型？**
- 点击输入框下方的模型名称药丸，在下拉列表中选择
- 每个对话可以独立使用不同的模型

**Q: 怎么调侧边栏宽度？**
- 拖动侧边栏左边缘的蓝色把手，左右拖动
- 最小 60px，最大 95% 视口宽度
- 宽度设置会跨标签页同步

**Q: 怎么备份模型配置？**
- 设置 → 模型配置 → 点击「导出」下载 JSON 文件
- 需要恢复时点击「导入」选择文件

**Q: 清除缓存会丢失什么？**
- **会清除：** 会话消息、日志、输入历史
- **不会清除：** 模型配置、主题、快捷键、翻译设置等个性化配置

**Q: 浮动按钮挡住了页面内容怎么办？**
- 拖拽浮动按钮到其他位置
- 位置会自动保存，刷新后仍在原位

**Q: 命令选择器不弹出？**
- 确保「网页自动化」开关已开启
- 确保输入框中以 `/` 开头且没有空格
