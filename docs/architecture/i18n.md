# i18n Module

## 模块概述

国际化模块基于 Vue 3 响应式系统实现轻量级多语言支持。使用 `ref` + `computed` 管理语言状态，提供 `t()` 翻译函数和 `useI18n()` composable，支持点号分隔的嵌套键路径和 `{varName}` 变量插值。

**源文件**:
- `src/i18n/index.ts` - i18n 核心逻辑
- `src/i18n/zh-CN.json` - 中文语言包
- `src/i18n/en-US.json` - 英文语言包

## 核心类型定义

```typescript
// 支持的语言
type Locale = 'zh-CN' | 'en-US';

// 消息结构（与 zh-CN.json 类型一致）
type Messages = typeof zhCN;

// 消息注册表
type MessageRegistry = Record<Locale, Messages>;

// useI18n 返回值
interface I18nComposable {
  t: (key: string, vars?: Record<string, string | number>) => string;
  locale: Ref<Locale>;
  setLocale: (l: Locale) => void;
}
```

## 实现细节

### 语言状态管理

```typescript
// 响应式语言状态（模块级单例）
const locale = ref<Locale>('zh-CN');

// 初始化（从 settings store 调用）
export function initI18n(initialLocale: Locale) {
  locale.value = initialLocale;
}
```

语言状态是模块级 `ref`，所有使用 `useI18n()` 的组件共享同一响应式引用。切换语言时，所有组件自动重新渲染。

### 翻译函数 (t)

```typescript
function t(key: string, vars?: Record<string, string | number>): string {
  const keys = key.split('.');
  let value: unknown = messages[locale.value];

  // 点号分隔的嵌套键遍历
  for (const k of keys) {
    if (value && typeof value === 'object' && k in value) {
      value = (value as Record<string, unknown>)[k];
    } else {
      return key; // 键不存在时返回 key 本身
    }
  }

  if (typeof value !== 'string') return key;

  // {varName} 变量插值
  if (!vars) return value;
  return value.replace(/\{(\w+)\}/g, (_, name) => String(vars[name] ?? ''));
}
```

**特性**:
- **点号路径**: `'settings.title'` -> `messages[locale].settings.title`
- **优雅降级**: 键不存在时返回 key 字符串本身，不抛出错误
- **变量插值**: `{varName}` 占位符被替换为 `vars[varName]`，缺失时替换为空字符串
- **类型安全**: `Messages` 类型从 `zhCN` 推导，TypeScript 编译时检查键路径

### useI18n Composable

```typescript
export function useI18n() {
  return {
    t,
    locale,
    setLocale: (l: Locale) => { locale.value = l; },
  };
}
```

返回模块级单例引用，所有组件共享同一个 `locale` ref 和 `t` 函数。

## 数据流

```
应用启动
    │
    ▼
App.vue onMounted
    │
    ├─ settingsStore.init()
    │      读取 settings.locale
    │
    ├─ initI18n(settingsStore.settings.locale || 'zh-CN')
    │      设置 locale.value
    │
    ▼
组件中使用
    │
    │ const { t, locale, setLocale } = useI18n()
    │
    │ <template>{{ t('settings.title') }}</template>
    │
    ▼
用户切换语言
    │
    │ setLocale('en-US')
    │      locale.value = 'en-US'
    │
    ▼
所有使用 t() 的模板自动重新渲染
    │
    ▼
App.vue watch(settings.locale)
    │ setLocale(val)
    ▼
持久化到 settingsStorage
```

## 配置与扩展

- **新增语言**: 创建新的 JSON 文件 -> 在 `messages` 注册表中添加 -> 扩展 `Locale` 类型
- **新增翻译键**: 在 `zh-CN.json` 和 `en-US.json` 中同时添加（保持同步）
- **变量插值格式**: `{varName}`，支持字母数字下划线
- **初始语言**: 由 `settingsStorage` 的 `locale` 字段决定，默认 `'zh-CN'`
- **无复数规则**: 不支持 pluralization（如 `1 item` vs `2 items`）
- **无日期/数字格式化**: 不提供 `Intl.NumberFormat` / `Intl.DateTimeFormat` 封装

## 已知限制

1. **类型安全依赖 zh-CN.json**: `Messages` 类型从中文 JSON 推导，如果英文包缺少某个键，TypeScript 不会报错（运行时返回 key 字符串）。
2. **无懒加载**: 两个语言包（各约 200 行 JSON）在模块导入时全部加载到内存，对于当前规模不是问题。
3. **无 SSR 兼容**: `locale` 是模块级 `ref`，在 SSR 场景下会在请求间共享状态（当前扩展不需要 SSR）。
4. **键路径无自动补全**: `t('settings.title')` 的参数是 `string` 类型，IDE 无法提供键路径自动补全（除非使用泛型约束）。
5. **插值无格式化**: `{count}` 只做简单字符串替换，不支持数字格式化（如千分位）、日期格式化等。
6. **无 fallback 语言**: 如果某个键在当前语言包中不存在，直接返回 key 字符串，不会 fallback 到默认语言。
