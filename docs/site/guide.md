## 1. 🚀 快速开始

### 1.1 安装扩展

1. 下载最新 CRX 包
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 开启右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」按钮
5. 选择解压后的文件夹，确认加载

安装成功后，浏览器右上角工具栏会出现图标，页面右下角出现浮动按钮。

### 1.2 首次配置 AI 模型

1. 点击浮动按钮或按 `Ctrl+`` ` 打开侧边栏
2. 点击右上角 ⚙️ 齿轮图标进入设置
3. 在「AI」标签页，点击「新建模型」
4. 点击提供商预设按钮（如 DeepSeek），自动填充
5. 填写 API Key，点击「保存」

> **提示：** 提供 10 个一键预设：OpenAI、Anthropic、DeepSeek、MiMo、Qwen、Kimi、智谱、百度、MiniMax、硅基流动。

### 1.3 打开侧边栏

| 方式 | 操作 | 说明 |
|------|------|------|
| 工具栏图标 | 点击浏览器右上角图标 | 最常用 |
| 键盘快捷键 | `Ctrl+`` ` | 可自定义 |
| 浮动按钮 | 点击页面右下角浮动按钮 | 任何页面可用 |

> **注意：** 侧边栏状态在所有标签页间同步。

### 1.4 浮动按钮

- **点击** — 打开/关闭侧边栏
- **拖拽** — 拖到任意位置（移动超 3px 才算拖拽）
- **位置记忆** — 自动保存，刷新后仍在原位

### 1.5 调整侧边栏宽度

拖动侧边栏左边缘手柄（最小 60px，最大 95% 视口宽度），宽度自动同步所有标签页。

## 2. 💬 AI 对话

### 2.1 支持的 AI 提供商（11 个）

| 提供商 | 代表模型 |
|--------|----------|
| OpenAI | GPT-4o、GPT-4、GPT-3.5 |
| Anthropic | Claude 3.5 Sonnet、Claude 4 |
| Google Gemini | Gemini 1.5 Pro、Gemini 2.0 |
| DeepSeek | DeepSeek-V3、DeepSeek-R1 |
| Qwen (通义千问) | Qwen-Max、Qwen-Plus |
| Kimi (Moonshot) | Moonshot-v1-128k |
| 智谱 (ChatGLM) | GLM-4 |
| 文心一言 | ERNIE-4.0 |
| 豆包 | Doubao-pro |
| Grok | Grok-2 |
| 自定义 | 任何 OpenAI 兼容的 API |

### 2.2 发送消息

在输入框输入文字，按 **Enter** 发送，**Shift+Enter** 换行。AI 实时流式输出回复，点击 ⏹ 可中断。

> **💡 试试这样说：**
>
> - "你好，介绍一下你自己"
> - "帮我写一封请假邮件"
> - "用 Python 写一个快速排序"
> - "解释一下什么是量子计算"

### 2.3 切换模型

点击输入框下方的**模型名称药丸** → 下拉列表选择 → 立即切换。每个对话独立使用不同模型。

### 2.4 深度思考模式

点击 💡 灯泡图标开启（仅支持 reasoning 的模型如 DeepSeek-R1、Claude 3.7+）。AI 会先展示可折叠的「💭 深度思考」区块。

> **💡 试试这样说：**
>
> - "分析一下 React 和 Vue 的优缺点，需要深度分析"
> - "帮我设计一个电商系统的架构，需要详细思考"

### 2.5 文件附件

| 方式 | 操作 |
|------|------|
| 点击上传 | 📎 回形针图标，支持多选 |
| 粘贴图片 | 直接粘贴截图 |
| 粘贴 URL | 自动抓取页面内容 |
| 粘贴本地路径 | 如 `C:\Users\...\file.txt` |

**支持格式：**

| 类型 | 格式 | 限制 | 处理 |
|------|------|------|------|
| 图片 | jpg, png, gif, webp, bmp, svg | 20 MB | 自动 OCR |
| 文本 | txt, log, csv 等 | 2 MB | 直接读取 |
| 代码 | js, ts, py 等 60+ 种 | 2 MB | 语言检测 |
| PDF | pdf | 10 MB | 逐页提取 |
| Word | doc, docx | 10 MB | 提取文本 |
| Excel | xls, xlsx, csv | 10 MB | 导出 CSV |

> **💡 试试这样说：**
>
> - （上传截图后）"提取图片中的文字并翻译成英文"
> - （上传 PDF 后）"总结这篇文档的要点"
> - （上传代码后）"检查这段代码的问题并给出改进建议"

### 2.6 选中文字自动发送

| 模式 | 行为 |
|------|------|
| **自动发送**（默认） | 直接发送给 AI |
| **手动发送** | 填入输入框，手动确认 |
| **关闭** | 不处理 |

### 2.7 消息管理

| 操作 | 方式 |
|------|------|
| 清空对话 | 头部 🗑️ 图标 |
| 删除单条 | 右键消息 → 删除 |
| 复制内容 | 右键消息 → 复制内容 |
| 中断回复 | ⏹ 停止按钮 |
| 滚动到底 | ⬇ 浮动按钮 |

### 2.8 消息内容交互

- **代码块** — 右上角复制按钮（1.5s 确认反馈）
- **表格** — 右上角下载按钮（导出 Excel）
- **深度思考** — 可折叠区块
- **错误** — 红色横幅；停止 — 黄色横幅

### 2.9 输入历史

在空输入框按 **↑** 浏览历史（最多 100 条），**↓** 前进。

### 2.10 上下文管理

默认携带最近 50 条消息，可在设置中调整（5-200）。

## 4. 🎤 语音控制

### 4.1 开启

点击输入框左侧 🎙️ 图标 → 语音面板 → 点击大麦克风按钮开始。

### 4.2 识别引擎

| 引擎 | 类型 | 特点 |
|------|------|------|
| Sherpa-ONNX（优先） | 本地离线 | 无需网络，中英双语 |
| Web Speech API（备选） | 在线 | 浏览器原生 |

### 4.3 状态指示

| 状态 | 颜色 | 文字 |
|------|------|------|
| 空闲 | 灰色 | "点击麦克风开始" |
| 聆听 | 绿色脉冲 | "正在聆听..." |
| 处理 | 主题色脉冲 | "处理中..." |
| 播报 | 紫色脉冲 | "播报中..." |

播报完成后自动回到聆听，无需重复点击。

### 4.4 语音消息类型

- 🗣️ 你 — 右对齐，主题色背景
- 🤖 AI — 左对齐，卡片背景
- ℹ️ 系统 — 居中，小字灰色
- ✅ 操作成功 / ❌ 操作失败

> **💡 试试这样说：**
>
> - "打开百度"
> - "搜索 AI 新闻"
> - "在站内搜索 Vue 教程"
> - "打开第三个"
> - "下一页" / "上一页"
> - "播放视频" / "暂停视频"
> - "今天天气怎么样"

> **注意：** 关闭自动化后变为纯聊天模式。

## 5. 🌍 智能翻译

### 5.1 翻译模式

| 模式 | 适合场景 |
|------|----------|
| 划词翻译 | 偶尔查词 |
| 自动翻译 | 整页阅读 |
| 点击翻译 | 按需翻译段落 |
| 关闭 | 不需要翻译 |

在设置 → 通用配置 → 翻译模式中选择。

### 5.2 划词翻译

选中文字 → 自动弹出浮窗 → 显示译文 → 复制按钮 → 点击外部关闭。

### 5.3 自动翻译

所有可见文本自动翻译，相同文本只翻译一次，`<code>` 元素保留不翻译，动态加载内容也自动翻译。

### 5.4 点击翻译

点击段落翻译，再次点击恢复原文，第三次显示译文。支持段落、列表、表格、标题等。点击表格行翻译整个表格。

### 5.5 目标语言（8 种）

中文、English、日本語、한국어、Français、Deutsch、Español、Русский

### 5.6 代码保护

`<pre>`/`<code>`/`<samp>` 整体跳过；含 `hljs`、`language-` 等类名的元素跳过；行内代码替换为占位符后恢复。

## 11. 💡 使用技巧

### 对话效率

- **指令越明确越好** — "点击登录按钮" 比 "帮我操作" 效果好
- **复杂任务拆分多步** — 分步执行更可靠
- **利用上下文** — "接着刚才的继续"
- **中断重来** — 点停止按钮，重新描述

### 文件处理

- **OCR + 翻译** — 上传截图要求"提取文字并翻译成英文"
- **PDF 分析** — 上传 PDF 要求"总结要点"
- **代码审查** — 上传代码要求"检查问题并给出改进建议"

### 翻译

- **划词翻译**适合偶尔查词，**自动翻译**适合整页阅读
- **点击翻译**最轻量，按需翻译不干扰阅读

### 设置

- **模型导入导出** — 团队共享配置
- **上下文 20-50** — 日常对话足够
- **缓存管理** — 定期清理保持流畅

## 12. ❓ 常见问题

**Q: 打开侧边栏没反应？** 检查是否配置了模型、API Key 是否正确、网络是否正常。

**Q: AI 回复很慢？** 减少上下文消息数、切换更快模型、检查网络。

**Q: 自动化无法点击？** 元素可能在 iframe 中或被遮挡，用更精确的描述重试。

**Q: 语音识别不准？** 确保麦克风权限、安静环境、说话清晰。

**Q: 文件上传失败？** 检查大小限制：图片 20MB、文本 2MB、PDF 10MB。

**Q: 怎么切换模型？** 点击输入框下方的模型名称药丸。

**Q: 怎么调侧边栏宽度？** 拖动左边缘手柄。

**Q: 怎么备份配置？** 设置 → 模型配置 → 导出。

**Q: 清除缓存丢失什么？** 清除会话/日志/历史，保留个性化配置。

**Q: 浮动按钮挡内容？** 拖到其他位置，自动保存。

**Q: 命令选择器不弹出？** 确保自动化开关已开启，输入以 `/` 开头。
