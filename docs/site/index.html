核心功能

💬

AI 多模型对话

支持 11 个 AI 提供商，GPT-4o、Claude、Gemini、DeepSeek 等主流大模型一键切换，流式输出，深度思考。

⚡

网页自动化

自然语言控制浏览器 — 点击、输入、滚动、搜索、导航。AI 自动分析页面结构，逐步执行操作。

🎤

语音控制

双引擎语音识别（本地 Sherpa-ONNX + Web Speech API），中英双语，连续对话，语音播报。

🔍

网页分析

智能分析当前页面内容，提取核心信息，生成结构化摘要。支持表格数据提取和关键信息定位。

🌍

智能翻译

划词翻译、自动翻译、点击翻译三种模式，8 种目标语言，代码智能保护，技术文档无障碍阅读。

📝

智能笔记

对话内容一键保存为笔记，支持 Markdown 格式导出。自动整理关键信息，构建个人知识库。

📎

文件处理

图片 OCR、PDF 提取、Word/Excel 解析、60+ 代码语言高亮。上传即分析，AI 读懂你的文件。

📊

图表与报告

AI 生成柱状图、折线图、饼图、雷达图，内联渲染。一键导出 PNG/JSON，自动生成文件报告。

📥

数据提取

从网页中智能提取结构化数据，支持表格、列表、商品信息等。一键导出为 JSON 或 Excel 格式。
