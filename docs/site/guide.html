AI Browser 使用指南 Chrome 扩展：AI 驱动的浏览器助手，集成对话、自动化、语音、翻译和文件处理。

🚀 快速开始

1.1 安装扩展

  1. 下载扩展包并解压到本地文件夹
  2. 打开 Chrome，地址栏输入 chrome://extensions/
  3. 开启右上角「开发者模式」开关
  4. 点击「加载已解压的扩展程序」按钮
  5. 选择解压后的文件夹，确认加载
chrome://extensions/ 页面，开发者模式开关和加载按钮

安装成功后，浏览器右上角工具栏会出现 AI Browser 图标。

1.2 首次配置 AI 模型

  1. 点击工具栏中的 AI Browser 图标，打开侧边栏
  2. 点击侧边栏右上角的 ⚙️ 齿轮图标进入设置
  3. 在「模型配置」标签页中，点击「+ 新建」按钮
  4. 点击提供商预设按钮（如 DeepSeek、OpenAI 等），自动填充大部分字段
  5. 填写你的 API Key
  6. 点击「保存」按钮
提示： 设置页提供 10 个一键预设：OpenAI、Anthropic、DeepSeek、MiMo、Qwen、Kimi、智谱、百度、MiniMax、硅基流动。点击即可自动填充 API 地址等字段，只需填写 API Key 即可。

1.3 打开侧边栏

方式操作说明
工具栏图标点击浏览器右上角的 AI Browser 图标最常用
键盘快捷键按 Ctrl+`默认快捷键，可在设置中自定义
浮动按钮点击页面右下角的浮动按钮任何页面都可用
注意： 侧边栏的状态会在所有标签页间同步。在一个标签页打开侧边栏，其他标签页也会自动打开。

1.4 浮动按钮

页面右下角有一个 48×48 像素的浮动按钮，可以：

  • 点击 — 打开/关闭侧边栏
  • 拖拽 — 按住拖动到页面任意位置（移动超过 3px 才算拖拽，否则视为点击）
  • 位置记忆 — 拖拽后的新位置会自动保存，刷新页面后仍在原位
提示： 浮动按钮悬停时会显示工具提示，提示当前设置的快捷键。

1.5 调整侧边栏宽度

  • 将鼠标移到侧边栏左边缘，光标变为 ↔ 拖拽手柄
  • 左右拖动调整宽度（最小 60px，最大 95% 视口宽度）
  • 宽度设置自动同步到所有标签页

  1. 在侧边栏底部的输入框中输入文字

2.3 切换模型

  1. 点击输入框下方工具栏中的模型名称药丸（显示当前模型名称）
  2. 在弹出的下拉列表中选择其他模型
  3. 点击后立即切换，后续消息使用新模型
提示： 下拉列表中会显示所有已配置的模型。如果列表为空，需要先在设置中添加模型。

2.4 深度思考模式

部分模型支持深度思考（如 DeepSeek-R1、Claude 3.7+）：

  1. 点击输入框下方的 💡 灯泡图标
  2. 图标高亮表示已开启
  3. 发送消息后，AI 会先展示思考过程（显示为可折叠的「💭 深度思考」区块）
  4. 思考完成后输出正式回答
注意： 深度思考模式仅对支持 reasoning 的模型生效。如果当前模型不支持，切换不会有任何效果。

2.8 消息内容交互

  • 代码块： 每个代码块右上角有 📋 复制按钮，点击后变为 ✅ 确认标记（1.5 秒后恢复）
  • 表格： AI 回复中的表格右上角有 📥 下载按钮，点击可导出为 Excel 文件
  • 深度思考区块： 可折叠的「💭 深度思考」区块，点击标题展开/折叠
  • 错误状态： 请求失败 → 红色错误横幅；手动停止 → 黄色横幅

2.9 输入历史

  1. 在空输入框中按 ↑ 键 → 浏览历史输入（从新到旧）
  2. 按 ↓ 键 → 前进到更新的历史
  3. 到达最新条目时恢复之前的草稿
  4. 最多保存 100 条历史记录

2.10 上下文管理

  • AI 每次请求会携带最近 N 条消息作为上下文
  • 默认 50 条，可在设置 → 用户配置中调整（范围 5-200）
  • 超过限制时，最早的消息会被自动裁剪
  • 裁剪不影响对话记录，只是不发送给 AI
提示： 上下文越多，AI 回答越有连贯性，但消耗的 token 也越多。建议根据使用场景调整。

🌐 网页自动化

3.1 工作原理

AI Browser 会自动分析当前页面的结构（按钮、链接、输入框等），将信息发送给 AI，AI 根据你的指令生成操作命令并逐步执行。

注意： 网页自动化需要在设置中开启「网页自动化」开关（默认开启）。关闭后 AI 仅作为聊天助手，不会执行任何页面操作。

3.2 自然语言操作

不需要记忆命令，直接用自然语言描述你想做的事：

"滚动到页面底部"
"点击搜索按钮"
"在搜索框中输入 Vue3 教程"
"帮我打开百度搜索 AI 新闻"
"总结一下这个页面的内容"
"把页面上的表格下载为 Excel"
"帮我登录，用户名是 admin，密码是 123456"

AI 会自动：分析页面结构 → 确定操作 → 逐步执行 → 遇错自动重试（最多 5 次）→ 最多执行 20 步。

🌍 智能翻译

5.1 翻译模式

模式怎么用适合场景
划词翻译选中文字后自动弹出翻译浮窗阅读时偶尔查词
自动翻译自动翻译进入视口的所有文本浏览外文网站
点击翻译点击文本段落触发翻译按需翻译特定段落
关闭不启用翻译功能不需要翻译

5.2 划词翻译

  1. 在页面上选中一段文字
  2. 自动弹出翻译浮窗，显示加载动画
  3. 翻译完成后显示译文
  4. 可点击「复制」按钮复制译文
  5. 点击浮窗外部或滚动页面自动关闭

5.3 自动翻译

  • 新进入视口的文本会自动触发翻译
  • 相同的文本只翻译一次，结果应用到所有匹配位置
  • 行内 <code> 元素会自动保留不翻译
  • 新动态加载的内容也会自动翻译

5.4 点击翻译

  1. 开启点击翻译模式
  2. 点击页面上的文本段落
  3. 该段落自动翻译并替换显示
  4. 再次点击 → 恢复原文
  5. 第三次点击 → 重新显示译文

特殊处理： 点击表格行 → 翻译整个表格；点击列表项 → 翻译整个列表。

5.5 翻译目标语言

支持 8 种目标语言：中文（默认）、English、日本語、한국어、Français、Deutsch、Español、Русский。

5.6 代码保护

翻译时自动识别并跳过代码内容：<pre>、<code>、<samp> 标签整体跳过；含 hljs、language- 等类名的元素跳过；行内代码替换为占位符，翻译后恢复。

💡 使用技巧

对话效率

  • 指令越明确越好 — "点击页面上的登录按钮" 比 "帮我操作一下" 效果好得多
  • 复杂任务拆分多步 — 分步执行比一步到位更可靠
  • 利用上下文 — AI 记得之前的对话，可以说"接着刚才的继续"
  • 中断重来 — AI 执行方向不对？点停止按钮中断，重新描述需求

文件处理

  • OCR + 翻译 — 上传截图后要求"提取图片中的文字并翻译成英文"
  • PDF 分析 — 上传 PDF 后要求"总结这篇文档的要点"
  • 代码审查 — 上传代码文件后要求"检查这段代码的问题并给出改进建议"

翻译

  • 划词翻译适合偶尔查词，自动翻译适合整页阅读
  • 点击翻译最轻量，按需翻译不干扰阅读
  • 翻译会自动过滤代码块，技术文档翻译更准确

设置

  • 模型导入导出 — 团队共享模型配置的最便捷方式
  • 上下文消息数 — 日常对话建议 20-50，长文档分析可调高
  • 缓存管理 — 定期清理保持扩展流畅

❓ 常见问题

Q: 打开侧边栏后没有任何反应？

检查：① 是否已配置至少一个 AI 模型 ② API Key 是否正确 ③ API 地址是否可访问 ④ 网络连接是否正常。

Q: AI 回复很慢？

减少「上下文消息数」设置；切换到更快的模型；检查网络延迟。

Q: 网页自动化无法点击某些元素？

元素可能在 iframe 中（暂不支持跨 iframe 操作）、被遮挡、或需要先手动触发。尝试用更精确的描述重试。

Q: 翻译不准确？

检查翻译目标语言设置；可以切换到「点击翻译」模式按需翻译。

Q: 语音识别不准确？

确保已授予麦克风权限；安静环境下效果更好；说话尽量清晰。

Q: 文件上传失败？

检查大小限制：图片 20 MB、文本/代码 2 MB、PDF/Office 10 MB。

Q: 怎么切换 AI 模型？

点击输入框下方的模型名称药丸，在下拉列表中选择。

Q: 怎么调侧边栏宽度？

拖动侧边栏左边缘的蓝色把手。最小 60px，最大 95% 视口宽度。

Q: 怎么备份模型配置？

设置 → 模型配置 → 点击「导出」下载 JSON 文件。恢复时点击「导入」。

Q: 清除缓存会丢失什么？

会清除： 会话消息、日志、输入历史。不会清除： 模型配置、主题、快捷键等个性化配置。

Q: 浮动按钮挡住了页面内容？

拖拽浮动按钮到其他位置，位置会自动保存。

Q: 命令选择器不弹出？

确保「网页自动化」开关已开启，且输入框中以 / 开头。
