# 小灵 LingBot — AI 语音浏览器助手

> 用语音或文字指挥 AI 帮你操作浏览器。

---

## 这是什么

小灵是一个 Chrome 扩展，安装后会在每个网页右下角出现一个悬浮按钮。点击打开侧边栏，你可以：

- **用中文和 AI 对话**，AI 能看到你当前浏览的网页内容
- **用语音控制浏览器**——说"打开百度搜索天气"，它就真的帮你打开
- **自动翻译网页**——选中文字翻译、整页自动翻译、点击段落翻译
- **整理笔记**——把网页内容一键收藏到笔记本，支持导出 Markdown/ZIP
- **解析文件**——上传 PDF/Word/Excel/图片，AI 直接读取内容回答问题

---

## 核心功能

### 🤖 AI 对话

接入 11 个主流 AI 提供商（OpenAI、Claude、DeepSeek、通义千问、Gemini、豆包、文心一言等），流式输出，支持文件附件和图片。

**和普通 AI 聊天的区别**：小灵的 AI 能看到你正在浏览的网页。你问"这个页面讲了什么"，它直接基于页面内容回答，不需要你复制粘贴。

### 🎙️ 语音控制

三种语音引擎可选：
- **Web Speech API**：浏览器内置，零配置，开箱即用
- **讯飞语音**：中文识别精度高，需要 API Key
- **火山引擎**：字节跳动的语音服务，需要 API Key

支持唤醒词（默认"小灵"）、连续对话、语音播报回复。

**语音能做什么**：打开网站、搜索内容、点击按钮、输入文字、滚动页面、翻译选中文本、生成笔记——几乎所有你能用鼠标键盘做的事。

### 🌐 智能翻译

三种翻译模式：
- **选中翻译**：鼠标选中文字，自动翻译
- **自动翻译**：页面滚动到哪里翻译到哪里，基于 IntersectionObserver 懒加载
- **点击翻译**：点击任意段落翻译

翻译时自动识别并跳过代码块，不会把代码翻译乱。

### 📝 网页笔记

选中网页上的文字，一键收藏到笔记本。笔记记录原文、来源 URL、滚动位置，下次点击可以直接跳转回原文位置。支持按标题分类、导出 Markdown、批量导出 ZIP。

### 📎 文件解析

支持上传和解析：
- **文档**：PDF、Word (.docx)、Excel (.xlsx)
- **图片**：OCR 识别中英文文字
- **代码**：70+ 种编程语言的语法高亮
- **数据**：CSV、JSON、Markdown

AI 读取文件内容后可以直接回答关于文件的问题，也可以生成新的文件（Excel、Word、PDF、图表）。

### 🖥️ 浏览器自动化

AI 理解页面结构后自动执行操作：
- 点击按钮、链接、菜单
- 在输入框中填写内容
- 滚动页面、导航到新页面
- 上传文件、拖拽滑块
- 控制视频播放/暂停
- 跨标签页操作（导航后自动在新标签页继续执行）

技术亮点：通过语义骨架提取理解页面，支持 Shadow DOM 和跨域 iframe，不依赖固定 CSS 选择器。

## 技术特点

- **多模型支持**：不绑定任何一家 AI，用户自由选择
- **本地语音识别**：Sherpa-ONNX WASM 引擎，离线可用，不上传语音数据
- **Shadow DOM 隔离**：不影响宿主网页的样式和功能
- **跨标签页同步**：设置、对话、抽屉状态在所有标签页间同步
- **Manifest V3**：符合 Chrome 最新扩展规范，安全合规
- **暗色模式**：5 种主题可选，自动适配系统偏好

## 安装方式

### 国内用户（推荐）

1. 下载 `ai-browser.zip` 并解压
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 完成！右下角会出现悬浮按钮

### 海外用户

从 Chrome Web Store 搜索 "LingBot" 安装。

## 快速开始

1. **配置 AI**：点击悬浮按钮 → 设置 → AI 配置 → 添加模型（输入 API Key）
2. **开始聊天**：在输入框输入问题，或按 `Ctrl+Shift+M` 打开面板
3. **试试语音**：切换到语音模式，说"小灵"唤醒，然后说出指令
4. **翻译网页**：选中任意文字，或在设置中开启自动翻译
5. **收藏笔记**：选中文字后点击「收藏」按钮

## 隐私说明

- 你的 API Key 存储在浏览器本地，不会上传到任何服务器
- AI 请求直接从你的浏览器发往 AI 提供商，不经过中间服务器
- 本地语音识别（Sherpa-ONNX）的语音数据不离开你的设备
- 网页内容仅在你主动发起对话时发送给 AI，不会后台采集
- 所有数据存储在 `chrome.storage.local`，卸载扩展即清除

## 常见问题

**Q: 支持哪些浏览器？**
A: Chrome 116+、Edge 116+、Brave 等 Chromium 内核浏览器。

**Q: 需要自己准备 API Key 吗？**
A: 是的。小灵不内置 AI 模型，你需要自己注册 AI 服务商获取 API Key。推荐 DeepSeek（便宜）或通义千问（有免费额度）。

**Q: 语音识别需要联网吗？**
A: Web Speech API 需要联网（浏览器内置服务）。讯飞和火山引擎需要联网。Sherpa-ONNX 引擎完全离线（需额外下载模型文件）。

**Q: 会影响网页速度吗？**
A: 不会。小灵使用 Shadow DOM 隔离，只在你点击悬浮按钮时才加载完整 UI。翻译使用懒加载，只翻译屏幕可见区域。

**Q: 数据安全吗？**
A: 所有数据存在浏览器本地。AI 请求走 HTTPS 直连服务商。不经过我们的服务器，不收集任何用户数据。
