# 发布指南

> **Cloudflare**（官网 + 存 zip）→ **Chrome Web Store**（安装）→ **Gumroad / 爱发电**（收款）→ 蓝奏云（zip 备用）。

---

## 总览

```
官网：Cloudflare Pages（国内外都能访问）
├── 中文页：产品介绍 + 下载按钮（R2 + 蓝奏云）+ 购买按钮（→ 爱发电）
└── 英文页：产品介绍 + 安装按钮（→ Chrome Web Store）+ 购买按钮（→ Gumroad）

安装：
├── 海外：Chrome Web Store 一键安装

收款：
├── 海外：Gumroad（自动发 License Key）
└── 国内：爱发电（自动发激活码）

引流：
├── 国内：吾爱破解 + B站 + 小红书
└── 海外：YouTube + Reddit + Product Hunt
```

## 一、官网：Cloudflare Pages

| 项目 | 说明 |
|------|------|
| 地址 | https://dash.cloudflare.com |
| 费用 | 永久免费，不限流量 |
| 特点 | 拖拽上传静态 HTML，免备案，国内外都能访问 |

**制作流程**：

1. 基于 `产品介绍-中文.md` / `产品介绍-English.md` 制作 HTML 页面
2. 注册 Cloudflare 账号 → Pages → 创建项目 → 拖拽上传
3. 获取 `xxx.pages.dev` 域名

**中文页内容**：

1. 插件名称 + 一句话介绍

4. 下载按钮 → Cloudflare R2直链
5. 购买按钮 → 爱发电
6. FAQ
```

**英文页内容**：

```
1. 插件名称 + 一句话介绍

4. Download ZIP 按钮 → Cloudflare R2直链

## 二、安装渠道

### Chrome Web Store（海外主力）

| 项目 | 说明 |
|------|------|
| 地址 | https://chrome.google.com/webstore/devconsole |
| 注册费 | $5（一次性） |
| 审核周期 | 首次 1-7 天，后续 1-3 天 |
| 安装方式 | 用户点击「添加到 Chrome」，一键完成 |
| 自动更新 | ✅ |

详细流程见 [六、Chrome Web Store 上架流程](#六chrome-web-store-上架流程)。

### zip 下载（两个地址，一主一备）

| 优先级 | 平台 | 地址 | 费用 | 定位 |
|--------|------|------|------|------|
| 主 | **Cloudflare R2** | https://dash.cloudflare.com/ → R2 | 免费 10GB + 无限流量 | 国内外都能访问，永久稳定 |
| 备 | **蓝奏云** | https://www.lanzou.com/ | 免费不限速 | 国内备用 |

**Cloudflare R2 操作**：

1. 登录 Cloudflare → R2 → 创建 Bucket（如 `lingbot-releases`）
2. 上传 `.output-store/lingbot-vX.Y.Z-xxxx.zip`
3. 开启公共访问，获取直链

**蓝奏云操作**：

1. 小号注册 → 上传同一个 zip → 获取永久直链

**官网下载区域**：

```
Download v1.8.17
├── [Cloudflare R2] 主下载
└── [蓝奏云] 备用下载
```

> Chrome Web Store 给海外用户一键安装，zip 给国内外所有用户手动下载。两个下载地址互为备份。

## 三、收款渠道

### 海外：Gumroad

| 项目 | 说明 |
|------|------|
| 地址 | https://www.gumroad.com |
| 手续费 | 10% |
| 特点 | 自带 License Key 自动发码，无需后端 |

**操作流程**：

1. 注册 Gumroad → 创建数字产品（类型选 License Key）
2. 定价：$2.99/月 或 $19.99/年
3. 批量生成激活码：`node scripts/gen-license.js --version X.Y.Z --count 500 --days 30 --output licenses.csv`
4. 上传 licenses.csv 到 Gumroad Keys 页面
5. 用户付款 → Gumroad 自动从 CSV 取码 → 发到用户邮箱

### 国内：爱发电

| 项目 | 说明 |
|------|------|
| 地址 | https://afdian.net |
| 手续费 | 6% |
| 特点 | 支持支付宝/微信，可配置自动回复发码 |

**操作流程**：

1. 注册爱发电 → 创建发电方案：月度 ¥3 / 年度 ¥29 / 终身 ¥69
2. 批量生成激活码（同上）
3. 配置自动回复：付款后自动发送激活码

### 收款链路

```
用户付款 → 平台自动发码 → 用户输入插件 → wasm 验证 → 激活成功
```

> 💡 激活码由本地私钥签名，wasm 内公钥验证。收款平台只负责"发码"，换平台不影响激活码体系。

## 六、Chrome Web Store 上架流程

### 注册

1. 访问 https://chrome.google.com/webstore/devconsole
2. Google 账号登录 → 支付 $5 → 同意协议

### 准备材料

| 材料 | 规格 |
|------|------|
| 扩展 zip | < 100MB |
| 商店图标 | 128×128 PNG |
| 宣传图 | 1280×800，至少 1 张 |
| 产品描述 | 英文（参考 `产品介绍-English.md`） |
| 隐私政策 | URL（可放 Cloudflare Pages） |

### 上传

1. 登录 Dashboard → New Item → 上传 zip
2. 填写名称、英文描述、类别 Productivity
3. 上传宣传图 → 填隐私政策 URL → Publish

### 审核

| 阶段 | 时间 |
|------|------|
| 初次提交 | 1-7 天 |
| 版本更新 | 1-3 天 |

### 审核红线

| 必须避免 | 可以使用 |
|----------|----------|
| `selfDefending: true` | JS 混淆（变量名、控制流） |
| `debugProtection: true` | Wasm 二进制 |
| `eval()` | stringArray + base64 |
| 远程代码执行 | transformObjectKeys |
| 未声明的权限 | — |

### Wasm 声明

```json
// wxt.config.ts → manifest
{
  "web_accessible_resources": [
    { "resources": ["wasm/*.js", "wasm/*.wasm"], "matches": ["<all_urls>"] }
  ]
}
```

### 版本更新

```bash
npm run build:store
# Dashboard → Upload new package → 等审核 1-3 天
```

## 八、隐私铁律
