# 发布指南

> 5 个维度，每个只做一件事：**上架**（用户装插件）→ **官网**（用户看介绍）→ **资源存放**（zip 放哪）→ **引流**（用户怎么来）→ **收费**（怎么收钱）。

---

## 总览

```
国内线：
├── 官网：free3v.do 静态页（产品介绍 + 下载按钮）
├── 资源：蓝奏云存 zip
├── 引流：吾爱破解 + 扩展迷 + 幕尘镜像 + B站 + 小红书
├── 收费：爱发电
└── 安装：用户从官网下载 zip → 手动加载已解压的扩展

海外线：
├── 官网：Gumroad 产品页（产品介绍 + 购买按钮 + 商店链接）
├── 上架：Chrome Web Store（一键安装 + 自动更新）
├── 资源：AnonFiles/Mega 存 zip（补充下载）
├── 引流：YouTube + Reddit + Product Hunt + Twitter + AlternativeTo
├── 收费：Gumroad（自动发码）
└── 安装：Chrome Web Store 一键安装 / zip 手动加载
```

## 一、上架渠道（用户在哪装插件）

### 国内

国内没有 Chrome Web Store，用户装插件的方式：**从官网/引流页下载 zip → 手动加载**。

```
1. 用户访问官网（free3v.do）或引流帖（吾爱破解等）
2. 点击下载按钮 → 蓝奏云下载 zip
3. 解压 zip
4. Chrome 打开 chrome://extensions/
5. 开启「开发者模式」
6. 点击「加载已解压的扩展程序」→ 选择解压后的文件夹
7. 完成！右下角出现悬浮按钮
```

### 海外

#### Chrome Web Store（主力）

| 项目 | 说明 |
|------|------|
| 地址 | https://chrome.google.com/webstore/devconsole |
| 注册费 | $5（一次性） |
| 审核周期 | 首次 1-7 天，后续 1-3 天 |
| 安装方式 | 用户在商店点击「添加到 Chrome」，一键完成 |
| 自动更新 | ✅ 商店自动推送新版 |

详细上架流程见 [六、Chrome Web Store 上架流程](#六chrome-web-store-上架流程)。

#### zip 手动加载（补充 + 保底）

Chrome Web Store 审核通过前、被拒时、或用户不愿从商店装时，用 zip 分发：

| 平台 | 地址 | 特点 |
|------|------|------|
| AnonFiles | https://anonfiles.com | 无需实名，单文件 5GB，永久外链 |
| Mega | https://mega.nz | 虚拟邮箱注册，加密存储，隐私性强 |

用户流程：官网/引流帖 → 点击「Download ZIP」→ 下载 → 解压 → Chrome 开发者模式加载。

#### Edge Add-ons（待实测）

Edge 是 Chromium 内核，理论上兼容，但本插件用了 Wasm、Shadow DOM、chrome.storage 等 API，**需先在 Edge 中实测以下功能再决定是否提交**：

- [ ] Wasm 加载正常
- [ ] Shadow DOM 挂载正常
- [ ] chrome.storage 读写正常
- [ ] 语音识别正常
- [ ] 跨标签页同步正常

实测通过后提交：https://partner.microsoft.com/dashboard/microsoftedge （免费）。

## 二、官网静态页（用户看产品介绍的地方）

官网 = 产品介绍页。所有引流渠道的链接最终都指向这里。官网上有下载/购买按钮，引导用户下一步操作。

### 国内官网：free3v.do

| 项目 | 说明 |
|------|------|
| 平台地址 | https://free3v.do |
| 费用 | 免费 |
| 特点 | 拖拽上传 HTML，秒生成随机域名，不用登录，不留账号痕迹 |
| 缺点 | 随机域名不利于 SEO |

**页面内容**（参考 `docs/发布/产品介绍-中文.md`）：

```
1. 插件名称 + 一句话介绍
2. 核心功能列表（3-5 个）+ 截图/GIF 演示
3. 安装教程（步骤图解）
4. 下载按钮 → 指向蓝奏云直链
5. 免费版 vs Pro 版对比
6. 购买激活码按钮 → 指向爱发电
7. 常见问题（3-5 个）
```

**制作流程**：

1. 基于 `产品介绍-中文.md` 制作 HTML 页面
2. 下载按钮链接到蓝奏云 zip 直链
3. 购买按钮链接到爱发电方案页
4. 上传到 free3v.do，获取访问链接
5. 把这个链接发到所有引流渠道

### 海外官网：Gumroad 产品页

海外不需要单独建站。**Gumroad 产品页 = 官网 = 收款页**，一个页面搞定：

## 五、收费渠道（怎么收钱）

### 国内收费

| 平台 | 地址 | 手续费 | 特点 |
|------|------|--------|------|
| **爱发电** | https://afdian.net | 6% | 国内最主流创作者付费平台，支持支付宝/微信 |
| **面包多** | https://www.mianbaoduo.com | 5% | 数字商品交易平台，支持自动发码 |
| **小鹅通** | https://www.xiaoe-tech.com | 6-10% | SaaS 收款页面，功能全，适合规模化 |

**爱发电操作流程**：

1. 注册 https://afdian.net 账号
2. 创建发电方案（如：月度 ¥29 / 年度 ¥199 / 终身 ¥399）
3. 配置自动回复：付款后自动发送激活码
4. 发码方式二选一：
   - **手动**：提前用 `gen-license.js` 批量生成一批码，粘贴到自动回复里逐个发
   - **自动**：对接 API，用户付款后调用脚本自动生成并发送（需要后端）

### 海外收费

| 平台 | 地址 | 手续费 | 特点 | 适合阶段 |
|------|------|--------|------|----------|
| **Gumroad** | https://www.gumroad.com | 10% | 最简单，自带 License Key 分发，无需后端 | **起步期首选** |
| **Lemon Squeezy** | https://www.lemonsqueezy.com | 5% + 50¢ | Gumroad 替代品，手续费更低，支持全球税务 | 有收入后切换 |
| **Stripe** | https://stripe.com | 2.9% + 30¢ | 最专业，费率最低，但需要自己搭后端 | 规模化后 |

**Gumroad 操作流程**：

```
1. 注册 https://www.gumroad.com 账号
2. 创建数字产品：
   ├── 产品名：LingBot Pro License
   ├── 价格：$9.99/月 或 $79.99/年
   ├── 产品类型：License Key（关键！选这个才能自动发码）
   └── 上传产品图 + 英文描述

3. 上传 License Key：
   ├── 先批量生成：
   │   node scripts/gen-license.js \
   │     --version 1.8.17 \
   │     --count 500 \
   │     --days 30 \
   │     --output licenses.csv
   ├── 进入 Gumroad 产品 → Keys 页面
   ├── 上传 licenses.csv
   └── Gumroad 自动从 CSV 中取码发给买家

4. 用户购买流程：
   ├── 用户在 Gumroad 付款（信用卡/PayPal）
   ├── Gumroad 自动扣款
   ├── 邮箱收到激活码
   └── 在插件内输入激活码 → wasm 验证 → 激活成功

5. 你只需要做：
   ├── 定期检查 CSV 余量，快用完就再生成一批
   ├── 处理退款/客服邮件

**Gumroad vs Lemon Squeezy vs Stripe**：

```
                    Gumroad          Lemon Squeezy    Stripe
─────────────────────────────────────────────────────────────

自动发 License Key  ✅ 原生支持      ✅ 原生支持       ❌ 需自建后端
全球支付方式        信用卡/PayPal    信用卡/PayPal     信用卡/更多
税务处理            平台处理         平台处理          需自己处理
技术门槛            零               低                高（需后端）
适合阶段            起步             成长期            规模化

### 收款与激活码的完整链路

```
用户付款 → 平台自动发码 → 用户输入插件 → wasm 验证 → 激活成功
   │                                    │
   │  Gumroad/爱发电                     │  wasm-license 内部
   │  自动从 CSV 取码                     │  Ed25519 签名验证
   │  发送到用户邮箱                      │  版本 + 有效期 + 设备
```

> 💡 核心逻辑：激活码由本地私钥签名，wasm 内公钥验证。收款平台只负责"发码"，不参与验证。所以换收款平台不影响激活码体系。

## 六、Chrome Web Store 上架流程

### 6.1 注册开发者账号

1. 访问 https://chrome.google.com/webstore/devconsole
2. 使用 Google 账号登录
3. 支付 $5 注册费（一次性）
4. 同意开发者协议

### 6.2 准备材料

| 材料 | 规格 | 说明 |
|------|------|------|
| 扩展 zip | < 100MB | `.output-store/lingbot-vX.Y.Z-xxxx.zip` |
| 商店图标 | 128×128 PNG | `icon.png` |
| 宣传图 | 1280×800 或 640×400 | 至少 1 张，最多 5 张 |
| 小宣传图 | 440×280 | 可选 |
| 产品描述 | 英文 | 详见 `docs/发布/产品介绍-English.md` |
| 隐私政策 | URL | 必须提供（可放 Gumroad 或 Neocities https://neocities.org） |

### 6.3 上传步骤

1. 登录 https://chrome.google.com/webstore/devconsole
2. 点击「New Item」
3. 上传 zip
4. 填写商品信息：
   - 名称：LingBot — AI Voice Browser Assistant
   - 描述：英文（参考 `产品介绍-English.md`）
   - 类别：Productivity
   - 语言：English
5. 上传宣传图（截图用英文界面）
6. 填写隐私政策 URL
7. 选择可见性：Public / Unlisted
8. 点击「Publish」

### 6.4 审核周期

| 阶段 | 时间 | 说明 |
|------|------|------|
| 初次提交 | 1-7 天 | 首次审核较慢 |
| 版本更新 | 1-3 天 | 后续更新较快 |
| 被拒 | 需修改后重新提交 | 查看拒绝原因并修复 |

### 6.5 审核注意事项

**必须避免**（会导致审核不通过）：

| 项目 | 原因 |
|------|------|
| `selfDefending: true` | 注入检测代码 |
| `debugProtection: true` | 注入 debugger 语句 |
| `domainLock` | 域名锁定 |
| `eval()` | 动态代码执行 |
| 远程代码执行 | 从外部加载并执行 JS |
| 未声明的权限 | manifest 中未声明但使用的权限 |

**可以使用**：

| 项目 | 说明 |
|------|------|
| JS 混淆 | 变量名随机、控制流扁平化、死代码注入 |
| Wasm 二进制 | 需在 manifest 声明 `web_accessible_resources` |
| stringArray + base64 | 字符串加密 |
| transformObjectKeys | 对象键名转换 |

### 6.6 Manifest 声明 Wasm 资源

```json
// wxt.config.ts → manifest.web_accessible_resources
{
  "web_accessible_resources": [
    {
      "resources": ["wasm/*.js", "wasm/*.wasm"],
      "matches": ["<all_urls>"]
    }
  ]
}
```

### 6.7 版本更新

```bash
# 1. 开发功能 → 提交代码
git add . && git commit -m "feat: xxx"

# 2. 打包（自动递增版本号 + 重新混淆 + 重新编译 wasm）
npm run build:store

# 3. 上传到 Chrome Web Store
# Developer Dashboard → 选择扩展 → Upload new package
# 上传 .output-store/lingbot-vX.Y.Z-xxxx.zip

# 4. 等待审核通过（1-3 天）
```

## 八、隐私避坑铁律（国内外通用）

| 规则 | 说明 |
|------|------|
| 放弃 GitHub/Gitee 分发 | 小号违规易封号，Git 提交永久留存邮箱，后台可溯源 IP |
| 账号隔离 | 国内、海外平台全部使用独立小号，不共用手机号/邮箱/浏览器/网络 |
| 网络隔离 | 操作匿名账号时不登录实名平台；海外站点搭配纯净 VPN |
| 内容脱敏 | 插件源码、网页截图、帖子文案删除所有个人标识 |
| 拒绝实名平台 | 阿里云/腾讯云 OSS 需要实名，匿名场景不用 |
| 不互动留痕 | 小号不评论、不点赞、不关注，减少行为画像追踪 |
