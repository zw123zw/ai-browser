## 📋 测试覆盖的功能点

### ✅ 已覆盖功能

1. **输入路由**
   - 内置命令识别（/stop, /help, /list）
   - 未知命令处理
   - AI 处理路由

2. **标签解析**
   - [command] 标签提取（单条/多条/嵌入自然语言）
   - [action] 标签检测
   - [need_full] 标签检测
   - [need_input] 标签提取
   - [FILE] 标签检测
   - 纯聊天判断
   - 聊天文本获取

3. **骨架提取**
   - 可点击元素识别（button/a/input/div[role=button]/div[cursor:pointer]）
   - 可见性过滤（display:none/visibility:hidden）
   - 视口过滤（viewport 模式 vs full 模式）
   - alerts 提取（role=alert/aria-live/class 含关键词）
   - 元素数量限制（viewport 模式最多 200 个）
   - 页面信息返回（url/title）

4. **命令执行**
   - 三重元素定位（elementId → fallbackSelector → 文本匹配）
   - click/type/scroll/keyboard/navigate 命令
   - 元素未找到处理
   - 未知命令处理
