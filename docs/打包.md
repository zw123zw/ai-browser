# 打包指南

## 命令总览

| 命令 | 输出 | 用途 |
|------|------|------|
| `npm run build` | `.output/release-v{版本}-{时间}/` | 构建（test + prod） |
| `npm run build:test` | 同上 | 仅构建 test |
| `npm run build:prod` | 同上 | 仅构建 prod |

---

## 1. 环境准备

### 1.1 Node.js

```bash
node --version
npm --version
npm install
```

### 1.2 Bash

构建脚本使用 Bash：

- macOS / Linux：直接使用系统 Bash
- Windows：使用 Git Bash 或 WSL

```bash
bash --version
```

---

## 2. 测试包（带日志）

```bash
npm run build:test
```

输出：`.output/release-v{版本}-{时间}/lingbot-debug-v{版本}-{时间}.zip`

- 包含 `VITE_LOG_ENABLED=true` 日志
- 用于开发调试
- 加载到 Chrome 后可看控制台输出

---

## 3. 生产包（上架用）

```bash
npm run build:prod
```

输出：`.output/release-v{版本}-{时间}/lingbot-v{版本}-{时间}.zip`

- 无日志
- WXT + Vue 构建
- 可直接上传 Chrome Web Store

### 内部流程

```
[1/4] 创建 release 目录
[2/4] 构建生产版本
[3/4] 构建测试版本
[4/4] 打包 zip 并清理临时构建目录
```

### Chrome Web Store 审核要点

| 允许 | 禁止 |
|------|------|
| esbuild 压缩 + mangle | javascript-obfuscator |
| 字符串压缩 | selfDefending / debugProtection |
| 常规代码拆分 | eval() / 远程代码执行 |

---

## 4. 文件结构

```
.output/
└── release-v{版本}-{时间}/
    ├── lingbot-v{版本}-{时间}.zip        ← 生产包（上架用）
    └── lingbot-debug-v{版本}-{时间}.zip  ← 测试包（带日志）
```

---

## 5. 故障排查

### 构建脚本无法执行

确认当前终端可运行 Bash：

```bash
bash scripts/build.sh
```

Windows 下优先使用 Git Bash 或 WSL。

### 构建后扩展异常

```bash
npx wxt build
# 加载 .output/chrome-mv3 测试
```

### zip 未生成

检查构建模式是否正确，以及 `.output/` 下是否生成了对应的临时目录。
