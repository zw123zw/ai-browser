2.3.2 新版系统 Prompt（强化「多条指令 + 顺序执行 + 格式约束」）

你是浏览器语音指令助手，根据用户语音、页面URL和页面HTML生成可执行指令。
严格遵守以下规则：
1. 所有可执行指令必须使用【code】和【/code】包裹；多条指令分行书写，**严格按照用户语音语义顺序排列**，一条指令占一行。
2. 单条指令格式：指令类型:参数；无参指令直接写指令类型。
3. 支持指令列表：
open_site:网址        打开指定网站
search:关键词        全局搜索关键词
site_search:关键词   站内搜索
open_item:名称       打开页面指定内容
page_next            下一页
page_prev            上一页
video_play           视频播放
video_pause          视频暂停
4. 若用户同时说出多个操作，必须逐条分行输出有序指令，不可合并、不可打乱顺序。
5. 若语音无法转为指令、属于闲聊对话，直接输出简短口语回复（100字内，无Markdown、无代码块），适合语音播报。
6. 仅输出指令或对话，禁止多余解释、注释、符号。

// src/command/parser.ts
import { Logger } from "@/utils/logger";

const log = new Logger("CommandParser");
const CMD_START = "【code】";
const CMD_END = "【/code】";

export type CommandType =
  | "open_site"
  | "search"
  | "site_search"
  | "open_item"
  | "page_next"
  | "page_prev"
  | "video_play"
  | "video_pause";

export interface CommandInfo {
  type: CommandType;
  params: string;
}

export interface SingleParseResult {
  success: boolean;
  command?: CommandInfo;
  error?: string;
}

export interface BatchParseResult {
  total: number;
  commandList: CommandInfo[];
  hasError: boolean;
  errorMsg?: string;
  plainText?: string;
}

/**
 * 解析单条指令片段
 */
function parseSingleCmd(cmdContent: string): SingleParseResult {
  const content = cmdContent.trim();
  if (!content) return { success: false, error: "指令内容为空" };

  const [type, ...paramArr] = content.split(":");
  const params = paramArr.join(":").trim();

  const validTypes: CommandType[] = [
    "open_site", "search", "site_search", "open_item",
    "page_next", "page_prev", "video_play", "video_pause"
  ];
  if (!validTypes.includes(type as CommandType)) {
    return { success: false, error: `非法指令类型：${type}` };
  }

  const noParamCmds: CommandType[] = ["page_next", "page_prev", "video_play", "video_pause"];
  if (!noParamCmds.includes(type as CommandType) && !params) {
    return { success: false, error: `指令 ${type} 缺少必填参数` };
  }

  return {
    success: true,
    command: { type: type as CommandType, params }
  };
}

/**
 * 批量解析AI返回文本，支持多条有序指令
 * @param rawText AI 原始输出
 * @returns 批量解析结果
 */
export function parseBatchCommand(rawText: string): BatchParseResult {
  log.info("开始批量解析指令", { rawText });
  const result: BatchParseResult = {
    total: 0,
    commandList: [],
    hasError: false
  };

  // 1. 分割所有指令块（按结束标记拆分）
  const cmdBlocks = rawText.split(CMD_END).filter(blk => blk.includes(CMD_START));
  // 无指令标记 = 纯对话文本
  if (cmdBlocks.length === 0) {
    result.plainText = rawText.trim();
    log.info("未识别指令，判定为纯对话");
    return result;
  }

  // 2. 逐条解析，保留原有顺序
  for (const block of cmdBlocks) {
    const startIdx = block.indexOf(CMD_START);
    const cmdContent = block.slice(startIdx + CMD_START.length).trim();
    const singleRes = parseSingleCmd(cmdContent);

    if (!singleRes.success) {
      result.hasError = true;
      result.errorMsg = singleRes.error;
      log.error("单条指令解析失败", singleRes.error);
      continue;
    }

    if (singleRes.command) {
      result.commandList.push(singleRes.command);
      result.total++;
    }
  }

  log.info("批量解析完成", { total: result.total, hasError: result.hasError });
  return result;
}
2.4.3 解析后分流逻辑（新版）
存在纯对话文本（无指令）：播报对话内容，播报结束 → 自动回到等待指令

解析成功 + 指令列表非空：按列表顺序串行执行所有指令（静默无播报），全部执行完毕 → 自动回到等待指令
