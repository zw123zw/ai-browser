输出干净 dist 文件夹， 原始源码封存。
每次版本更新重新混淆 JS、重新编译 wasm，算法轻微改动，旧版破解工具失效；
设置本地使用时长 / 次数隐性校验，即使激活，长期使用随机弹出二次验证；

不把完整功能逻辑暴露在前端，能做本地离线限制就全部塞进 wasm 二进制。

浏览器插件匿名分发完整总结（国内 + 海外，全程不泄露隐私，避开 GitHub/Gitee）核心前提
坚决不用 GitHub/Gitee：多账号违规、Git 提交永久留邮箱、后台留存 IP，极易溯源，不适合匿名；
全程单独小号 / 免注册平台，不绑定实名手机号、微信、日常邮箱；
插件源码、网页、发帖文案删除所有姓名、微信、ID、公司等个人信息；
分两大块：文件存储（放插件 zip）、静态展示页（介绍 + 下载按钮）、引流渠道（获取大量用户）。
一、国内方案（面向国内用户，流量最大、访问最快、零实名泄露）
1. 插件 zip 存储（首选：蓝奏云）官网：https://www.lanzou.com/ 备用：lanzoui.com / lanzouw.com免费规则
永久免费、空间不限、下载不限速，访客无需登录；
单文件上限 100MB，浏览器插件完全够用；
注册不用强制实名，小号随便填昵称，不填真实信息。
匿名操作要点
全新手机号注册独立小号，不和微信 / 日常账号互通；
主页空白、简介不留任何联系方式；
只分享永久直链，不透露账号名。
临时替代（短期分发，免注册）奶牛快传、文叔叔：免登录上传，链接限时，适合短期小范围分享，不适合长期引流。
2. 国内匿名静态展示页（放插件介绍、安装教程、蓝奏云下载链接）① free3v.do（最强推荐，免注册零账号）拖拽上传 html 页面 + 资源，秒生成随机域名，不用登录、不留账号痕迹，完全无身份绑定；缺点随机域名不利于 SEO。② 不推荐：Gitee Pages必须账号，会留下仓库、提交记录，存在隐私泄露风险，全程避开。
3. 国内高流量引流渠道（精准插件用户，全程只放匿名链接）
吾爱破解论坛（国内插件第一流量池）
注册独立小号发帖，板块「原创软件 / 浏览器扩展」，仅贴 free3v 网页 + 蓝奏云链接，不暴露任何账号；帖子长期被百度收录，持续自然下载。
第三方插件收录站（自带海量用户，不用自己引流）
扩展迷extfans.com、幕尘镜像chrome.zzzmh.cn
提交仅上传 zip + 写介绍，无需提供任何个人账号 / 仓库，平台自带搜索流量。
泛流量渠道（普通人多）
B 站、小红书、抖音小号发演示视频，简介只放下载链接，主页不留微信 / QQ。
技术社区：掘金 / V2EX 小号发文，仅贴匿名页面链接。
国内最优组合（流量 + 隐私双拉满）蓝奏云存插件 zip + free3v.do 做下载介绍页 + 吾爱破解发帖 + 提交插件镜像站收录


二、海外方案（面向全球用户，完全匿名，无实名要求）
1. 海外插件文件存储（免费匿名）AnonFiles无需实名邮箱注册，单文件上限 5GB，永久外链，免费带少量广告，适合存放插件安装包。Mega虚拟邮箱注册小号，加密存储，外链分享，隐私性更强。
2. 海外匿名静态展示站（全球访问、免实名）① Neocities（长期稳定首选）仅用 ProtonMail 虚拟邮箱注册，昵称随便填，不上传真实信息，免费额度足够插件介绍页，Google 收录好，海外开发者能搜到。② host-my-page.com（免注册，零痕迹）直接拖拽网页文件夹，自动生成分享链接，不用注册账号，适合临时分发。③ IPFS 去中心化托管（PinMe）无需服务器、无需账号，去中心化存储，无平台后台记录你的上传 IP，极致隐私，免费不限流量。避雷：Vercel/Netlify必须绑定 GitHub/Git 账号，会间接关联身份，匿名场景不要用。3. 海外高流量引流渠道（精准海外插件用户）
Reddit r/chrome_extensions：专门浏览器插件板块，发帖只放 Neocities/IPFS 匿名链接；
Greasyfork：脚本类插件全球最大平台，提交仅上传 zip，不用绑定代码仓库；
Product Hunt：工具类插件一次性爆发大量海外下载；
小众开发者论坛：仅贴匿名站点链接，不提任何账号。
海外最优组合AnonFiles 存插件包 + Neocities 搭建介绍官网 + Reddit/Greasyfork 引流三、通用隐私避坑铁律（国内外通用，防止身份泄露）
彻底放弃 GitHub/Gitee：小号违规易封号，Git 提交永久留存邮箱，后台可溯源 IP，无法完全隐身；
区分账号隔离：国内、海外平台全部使用独立小号，不共用手机号、邮箱、浏览器、网络；
网络隔离：操作匿名账号时，不登录微信、QQ、抖音等实名平台；海外站点搭配纯净 VPN，避免真实 IP 泄露；
内容脱敏：插件源码、网页截图、帖子文案删除所有个人标识（姓名、手机号、旧 ID、社交账号）；
拒绝实名平台：阿里云 / 腾讯云 OSS 需要实名，匿名场景绝对不用；
不互动留痕：小号不评论、不点赞、不关注任何人，减少行为画像追踪。
四、两套最简落地方案（直接照抄）方案 A：只做国内用户（推荐）
文件：蓝奏云独立小号上传插件 zip，复制直链；

方案 B：海内外同步分发
国内：蓝奏云 + free3v.do；
海外：AnonFiles + Neocities 静态页；
引流：国内吾爱 + 插件镜像站；海外 Reddit+Greasyfork；
两套账号完全隔离，不互通任何信息。
