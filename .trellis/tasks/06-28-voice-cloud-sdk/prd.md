# 语音识别引擎扩展：火山引擎 + 操作手册

## Goal

在现有语音系统（Web Speech API + 讯飞）基础上，新增火山引擎（字节）作为第三个识别引擎选项，并在语音配置页面嵌入完整的操作手册，指导用户如何申请各服务商的 API Key 并配置。

## Decision (ADR-lite)

**Context**: 当前支持 Web Speech API（海外/零配置）和讯飞（国内/填 Key）。用户需要更多国内引擎选择，且申请 Key 的流程对新手不直观。

**Decision**:
1. 新增火山引擎（CORS 友好、免费额度最大方、JS SDK 直连）
2. 百度/腾讯因 CORS 限制暂不接入
3. 在语音配置页面内嵌操作手册（不跳转外部文档）

**Consequences**: 引擎从 2 个变为 3 个，用户有更多国内选择；操作手册内嵌降低配置门槛。

## Requirements

### 1. 新增火山引擎

- 实现 `VolcengineEngine` 类，实现 `VoiceEngine` 接口
- WebSocket 流式识别，音频格式 16kHz/16bit/mono PCM
- 配置字段：`volcengineAppId` + `volcengineAccessToken`
- 在 `voice-manager.ts` 的 `createEngine()` 中添加分支
- 在 `stores/voice.ts` 的 `EngineType` 类型中添加 `'volcengine'`

### 2. 语音配置操作手册

#### Tab 1：快速开始

**语音助手是什么？**
小灵的语音助手让您通过说话控制浏览器。说"你好，小灵"唤醒后，直接说出指令即可执行操作，如"打开百度"、"搜索今天的新闻"、"点击第一个结果"等。

**3 步开始使用：**

**① 选择识别引擎**
- 海外用户 → 选 **Web Speech API**（零配置，直接用）
- 国内用户 → 选 **讯飞语音** 或 **火山引擎**（需注册获取 Key）

**② 填入 API Key（仅讯飞/火山需要）**
- 按照"引擎配置" tab 的步骤获取 Key
- 填入对应输入框，点击保存

**③ 开始使用**
- 打开语音面板（点击工具栏麦克风图标或按 Ctrl+Shift+M）
- 说"你好，小灵"唤醒
- 说出你的指令，如"打开B站"

**引擎对比一览：**

| | Web Speech API | 讯飞语音 | 火山引擎 |
|--|---------------|---------|---------|
| 适用场景 | 海外用户、快速体验 | 国内用户、方言识别 | 国内用户、大额需求 |
| 免费额度 | 无限（浏览器内置） | 50 万次/年 | 50 万分钟 |
| 配置难度 | ⭐ 零配置 | ⭐⭐ 中等 | ⭐⭐ 简单 |
| 需要的 Key | 无 | AppID + APIKey + APISecret | AppId + AccessToken |
| 中文识别 | 一般 | ⭐⭐⭐ 顶级 | ⭐⭐⭐ 优秀 |
| 方言支持 | 有限 | 20+ 方言 | 一般 |
| 嘈杂环境 | 一般 | ⭐⭐⭐ 降噪强 | ⭐⭐ 较好 |
| 网络要求 | 需访问 Google | 国内直连 | 国内直连 |

#### Tab 2：引擎配置

**▎Web Speech API**

无需任何配置，Chrome/Edge 浏览器原生支持。

- ✅ 优点：零配置、免费、开箱即用
- ❌ 限制：需要能访问 Google 服务（国内网络无法直接使用）
- 💡 适用：海外用户、快速体验语音功能

如果提示"网络错误"，说明无法连接 Google 服务。请切换到讯飞或火山引擎。

---

**▎讯飞语音听写**

**申请步骤：**

**Step 1：注册讯飞开放平台账号**
- 访问 https://www.xfyun.cn/
- 点击右上角"注册"
- 支持手机号注册（推荐）或邮箱注册
- ⚠️ **必须完成实名认证**，否则无法创建应用

**Step 2：创建应用**
- 登录后进入"控制台"
- 点击"创建新应用"
- 填写应用名称（如"小灵浏览器助手"）
- 应用平台选择 **"Web"**
- 点击"提交"
- 创建成功后在应用列表中找到刚创建的应用
- 记下 **App ID**（8 位字母数字，如 `409873f8`）

**Step 3：开通语音听写服务**
- 进入应用详情页
- 找到"语音听写"服务，点击"开通"
- 阅读并同意服务协议
- 开通成功后进入"接口鉴权信息"页面

**Step 4：获取 API Key 和 API Secret**
- 在"接口鉴权信息"页面可以看到：
  - **API Key**：32 位字符串，如 `fc9f3cf011bca6fc037b5c362f54babb`
  - **API Secret**：32 位字符串，如 `MWViYTdkN2E5YzVkOTk2NjRjMjEyZDhk`
- 复制这两个值

**Step 5：填入小灵设置**
- 回到小灵设置 → 语音配置
- 引擎选择"讯飞语音"
- 将 App ID、API Key、API Secret 分别填入对应输入框
- 点击"保存"

**各字段含义：**

| 字段 | 说明 | 在哪里找 | 格式示例 |
|------|------|---------|---------|
| 讯飞 App ID | 应用唯一标识，用于 WebSocket 鉴权时识别你的应用 | 应用详情页顶部 | `409873f8` |
| 讯飞 API Key | 接口调用凭证，用于 HMAC-SHA256 签名验证身份 | 接口鉴权信息页 | `fc9f3cf011bca6fc...` |
| 讯飞 API Secret | 签名密钥，与 API Key 配合生成安全的鉴权 URL | 接口鉴权信息页 | `MWViYTdkN2E5YzVk...` |

⚠️ **三个字段缺一不可**，填错任何一个都会提示"鉴权失败"。

---

**▎火山引擎语音识别**

**申请步骤：**

**Step 1：注册火山引擎账号**
- 访问 https://console.volcengine.com/
- 点击"注册"
- 支持手机号注册
- ⚠️ **建议完成实名认证**（部分功能可能需要）

**Step 2：开通语音识别服务**
- 登录控制台
- 搜索"语音技术"或在"人工智能"分类下找到
- 点击"语音识别" → "开通服务"
- 选择"一句话识别"或"实时语音识别"

**Step 3：创建应用**
- 在语音识别页面点击"创建应用"
- 填写应用名称（如"小灵浏览器助手"）
- 应用平台选择 **"Web"**
- 点击"确认创建"
- 创建成功后获得 **App ID**

**Step 4：获取 Access Token**
- 在应用详情页 → "鉴权管理" 或 "密钥管理"
- 获取 **Access Token**
- ⚠️ Token 长期有效，但建议定期检查是否过期

**Step 5：填入小灵设置**
- 回到小灵设置 → 语音配置
- 引擎选择"火山引擎"
- 将 App ID 和 Access Token 填入对应输入框
- 点击"保存"

**各字段含义：**

| 字段 | 说明 | 在哪里找 | 格式示例 |
|------|------|---------|---------|
| 火山 App ID | 火山应用的唯一标识，用于连接时识别应用 | 应用详情页 | 字符串 |
| 火山 Access Token | 接口调用凭证，直接用于 WebSocket 连接鉴权 | 鉴权管理页 | 较长字符串 |

#### Tab 3：权限说明

**🎤 麦克风权限**

语音助手需要使用麦克风才能识别您的语音。

**为什么需要麦克风？**
- 语音识别引擎需要实时采集您的声音
- 音频数据仅在识别过程中临时处理，不会永久存储
- 关闭语音面板后，麦克风立即释放

**如何授权？**
- 首次使用时，浏览器会弹出权限请求：**"小灵想要使用您的麦克风"**
- 点击"允许"即可
- 如果误点了"拒绝"，可以点击地址栏左侧的 🔒 图标 → 麦克风 → 改为"允许"

**权限状态检查：**
- 地址栏左侧显示 🎤 图标 = 已授权
- 地址栏左侧显示 🔇 图标 = 已拒绝，需要手动开启

**⚠️ 重要提示：**
- 麦克风权限是浏览器级别的，不是网页级别的
- 如果您在某个网站拒绝了麦克风权限，只影响该网站
- 扩展的麦克风权限需要在扩展管理页面单独设置

---

**🌐 网络权限**

| 引擎 | 需要的网络 | 说明 |
|------|-----------|------|
| Web Speech API | Google 服务 | 音频发送到 Google 服务器识别 |
| 讯飞语音 | 国内网络 | WebSocket 直连 `wss://iat-api.xfyun.cn` |
| 火山引擎 | 国内网络 | WebSocket 直连火山 API 服务器 |

- 讯飞和火山引擎在国内网络环境下可直接使用，不需要科学上网
- Web Speech API 需要能访问 Google 服务，国内用户建议切换引擎

---

**🔒 数据安全与隐私**

**音频数据如何处理？**

| 引擎 | 音频去向 | 存储情况 |
|------|---------|---------|
| Web Speech API | 发送到 Google 服务器 | Google 可能用于改进服务 |
| 讯飞语音 | 发送到讯飞服务器 | 讯飞声明不存储用户音频 |
| 火山引擎 | 发送到火山服务器 | 火山声明按隐私政策处理 |

**小灵本身：**
- ❌ 不存储任何音频数据
- ❌ 不上传音频到小灵自己的服务器
- ❌ 不记录语音识别日志（除非开启调试模式）
- ✅ 识别结果仅在本地浏览器中处理
- ✅ 关闭语音面板后，所有临时数据清除

**API Key 安全：**
- 您的 API Key 存储在浏览器本地（chrome.storage.local）
- 不会发送到小灵的任何服务器
- 但 Key 会发送到对应引擎的服务器进行鉴权
- 建议定期在服务商控制台检查 Key 使用情况

#### Tab 4：注意事项

**📌 使用技巧**

**唤醒词使用：**
- 默认唤醒词："你好，小灵"
- 说唤醒词后，等待提示音再继续说指令
- 也可以连续说："你好小灵打开百度"（系统会自动分离）
- 唤醒词可在设置中自定义

**识别效果优化：**
- 🔇 保持环境安静，减少背景噪音
- 🎤 麦克风距离嘴巴 20-50cm 最佳
- 🗣️ 语速适中，不要太快
- ⏸️ 说话停顿 1-2 秒后自动识别为一条完整指令

**指令示例：**
- "打开百度" — 打开网址
- "搜索今天的科技新闻" — 全网搜索
- "点击第一个结果" — 点击页面元素
- "向下滚动" — 滚动页面
- "帮我总结这个页面" — AI 分析
- "今天天气怎么样" — 普通聊天

**⚠️ 已知限制**

**Web Speech API：**
- 国内网络无法使用（需科学上网）
- 长时间无语音输入会自动断开，需要重新唤醒
- 识别准确率受网络质量影响
- 不支持自定义热词

**讯飞语音：**
- 需要实名认证才能创建应用
- 免费额度 50 万次/年，超出需付费
- API Key 泄露可能导致他人盗用您的额度
- 建议在讯飞控制台设置 IP 白名单（如支持）

**火山引擎：**
- 免费额度 50 万分钟，用完需付费
- 方言识别能力弱于讯飞
- Access Token 泄露风险同上

**通用限制：**
- 语音识别不是 100% 准确，重要操作建议确认
- 嘈杂环境（如地铁、餐厅）识别率显著下降
- 多人同时说话时识别效果差
- 专业术语、人名、地名可能识别不准确

---

**💡 最佳实践**

1. **选择合适的引擎**
   - 海外用户 → Web Speech API
   - 国内用户、需要方言支持 → 讯飞
   - 国内用户、大额使用 → 火山引擎

2. **保护您的 API Key**
   - 不要分享给他人
   - 定期在服务商控制台查看使用量
   - 发现异常使用立即重置 Key

3. **合理使用免费额度**
   - 讯飞：50 万次/年，日常使用完全够用
   - 火山：50 万分钟，约 8333 小时，非常充裕
   - 如果额度紧张，可以关闭唤醒词功能减少误识别消耗

4. **网络环境**
   - 确保网络稳定，Wi-Fi 环境最佳
   - 移动数据网络可能有延迟
   - VPN 可能影响连接速度

#### Tab 5：常见问题

**Q: 提示"麦克风权限被拒绝"怎么办？**
A: 点击浏览器地址栏左侧的 🔒 图标 → 找到"麦克风" → 改为"允许"。然后刷新页面重试。

**Q: Web Speech API 提示"网络错误"？**
A: Web Speech API 依赖 Google 服务，国内网络无法直接使用。请切换到讯飞或火山引擎。

**Q: 讯飞提示"鉴权失败"？**
A: 检查三个字段是否都正确填入：
- App ID 是否正确（8 位）
- API Key 是否有空格或多余字符
- API Secret 是否正确
- 确认已在讯飞控制台开通"语音听写"服务

**Q: 火山引擎连接失败？**
A: 检查以下几点：
- Access Token 是否正确复制（没有多余空格）
- Token 是否过期（在火山控制台重新获取）
- 网络是否正常

**Q: 识别不准确怎么办？**
A:
- 确保环境安静
- 麦克风距离嘴巴 20-50cm
- 语速适中，吐字清晰
- 如果某个引擎效果差，尝试切换到另一个引擎
- 讯飞在中文和方言识别上表现最佳

**Q: 说唤醒词没反应？**
A:
- 确认语音面板已打开（状态栏应显示"等待唤醒词"）
- 确认麦克风权限已授权
- 尝试说得更清楚一些
- 检查唤醒词是否被修改过（设置 → 语音配置 → 唤醒词）

**Q: 语音面板打开后一直在转圈？**
A:
- 检查网络连接
- 如果使用讯飞/火山，检查 Key 是否正确配置
- 尝试关闭面板重新打开

**Q: 切换引擎后需要重新配置吗？**
A: 是的，每个引擎需要独立配置 Key。切换后之前的 Key 配置会保留，不需要重新填入。

**Q: 免费额度用完了怎么办？**
A:
- 讯飞：在讯飞控制台查看用量，可以等待下一年重置或购买付费套餐
- 火山：在火山控制台查看用量，可以购买付费套餐
- 或者切换到另一个引擎继续使用

**Q: 麦克风被其他应用占用怎么办？**
A: 关闭其他使用麦克风的应用（如微信语音、Teams、Zoom 等），然后重新打开语音面板。

## Technical Notes

### 火山引擎 API 参考

- 文档：https://www.volcengine.com/docs/6561/97465
- WebSocket 流式识别接口
- 音频格式：16kHz, 16bit, mono PCM
- 免费额度：新人 50 万分钟实时转写

### 火山引擎 vs 讯飞对比

| 维度 | 讯飞 | 火山引擎 |
|------|------|---------|
| 免费额度 | 50 万次/年 | 50 万分钟 |
| 鉴权方式 | HMAC-SHA256 签名 URL | Access Token 直连 |
| 配置字段 | 3 个（AppID + Key + Secret） | 2 个（AppId + Token） |
| 方言支持 | 20+ 方言 | 一般 |
| CORS | ✅ WebSocket 直连 | ✅ WebSocket 直连 |

### 火山引擎引擎实现要点

参考 `iflytek-engine.ts` 的架构：
1. `getUserMedia` 获取麦克风
2. `AudioContext` + `ScriptProcessorNode` 采集 PCM
3. `WebSocket` 连接火山 API
4. 第一帧发送参数，后续帧发送音频数据
5. 最后一帧标记结束
6. 解析返回的 JSON 获取识别文本
7. 支持 VAD（静音检测自动结束）
8. final 结果后重连继续监听

与讯飞引擎的主要差异：
- 鉴权方式不同（Token vs HMAC 签名）
- WebSocket 协议格式不同（火山有自己的帧格式）
- 返回 JSON 结构不同
